\begin{abstract}
This supplement locates physical choices at MiniLinq's existing macro boundaries
and specifies one arena-based backend family. Its checked private overlay
refines named Yannakakis semijoins into versioned providers,
consumer-local filters, immutable survivor views, and exact group accesses.
Exact reduction and conservative predicate transfer have separate evidence
and preservation contracts. Administrative rules map to algorithm dispatches,
runtime scan steps, Rust records, and existing compiler extension points.
An implemented integer block backend exercises exact reduction, independently
compiled access choices, reusable exact keys, and caller-owned macro aliases
through declared contextual syntax within the existing physical stage order.
A bounded semantic model accompanies the fuller proposed overlay.
\end{abstract}
