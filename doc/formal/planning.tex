\section{CQ-to-RA nanopasses}
\label{sec:planning}
The implemented chain is CQ $\to$ CQ-NF $\to$ VO $\to$ VO $\to$ RA.
Normalization rewrites a complete CQ program; ordering chooses a valuation
schedule; optional reduction inserts clause-local restrictions; elaboration
emits named RA. Each constructor checks its target contract. Separately callable
correspondence checks are specified in Section~\ref{sec:pass-contracts}.
Rules in this section describe successful construction on the checked domain;
abstract laws are explicitly identified and registered as such in
\path{rules.tsv}. Leibniz admissibility and functional extensionality remain
semantic premises, not properties inferred by these passes. Rust computations
may be partial; their written chain and Before constraints are retained.

The seen-name set used by A-Variable and A-Repeat is reset for every atom
occurrence. Sharing a name across atoms creates a natural join directly, not
a fresh variable and identity. The written bound environment remains global.

\subsection{Normalization: CQ to CQ}
\label{sec:prefix-planning}
For an atom at written clause $i$, walk its arguments left to right against the
declared column types $\tau_j$. Let $B$ contain bare variables and let-bound
names from earlier source clauses, $L$ the distinct names already seen in
this atom, and $A$ all bare names supplied by this atom but absent from $B$.
Maintain atom-local lists $\mathit{before},\mathit{after}$ and rewritten
arguments $\bar a'$. Each rule
appends its resulting argument to $\bar a'$. Generated $k$ starts at
\code{__cq_i_j}, appending underscores until absent from all source identifiers
and earlier generated names. The argument cases are tested in the order shown.
\begin{mathpar}

\Rule{A-Variable}{a_j=x\quad x\notin L}
 {a_j\leadsto_{NF}x\quad[L:=L\cup\{x\}]}

\Rule{A-Repeat}{a_j=x\in L\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[k=x]]}

\Rule{A-Wildcard}{a_j=\_\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\text{unconstrained witness}]}

\Rule{A-Constant}{a_j\text{ is a literal}\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[k=a_j]]}

\Rule{A-Prefix}{a_j=e\text{ is a remaining expression}\quad
 \uses(e,A)=\emptyset\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{before}:=\mathit{before}\concat[\mathsf{let}\ k:\tau_j=e]]}

\Rule{A-Local}{a_j=e\text{ is a remaining expression}\quad
 \uses(e,A)\ne\emptyset\quad k,v\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[\mathsf{let}\ v:\tau_j=e,\ k=v]]}
\end{mathpar}
Literal recognition is \code{syntax::equality::literal}, including
parenthesized and negated literals. Identities are relational clauses, not
Rust guards. Replace each atom by
$\mathit{before}\concat[R(\bar a')]\concat\mathit{after}$.
Copy constraints, residual guards and lets; normalize branch bodies recursively
with inherited prefix bindings and fresh names. Only common interface names
escape a block. A computed head becomes a final typed Rust bind using its
result declaration, and the head becomes variable-only. Declarations remain
unchanged and the constructor checks NF; there is no separate normalization
correspondence checker.

\subsection{Dependency facts and ordering}
\label{sec:planning-order}
Number \emph{all} normal-form body clauses $0,\ldots,m-1$. Atom identifiers in
VO and hypergraph analysis use these indices, including gaps occupied by guards
and lets. Let $T$ be all names supplied by lets in the body, $B_w$ the written
prefix, and $\bar O_i,R_i$ the provided list and required set of clause $i$.
\begin{mathpar}

\Rule{D-Atom}{c_i=A(\bar x)}
 {B_w;T\vdash c_i\triangleright(\bar x,\set(\bar x)\cap T)}

\Rule{D-Guard}{R=\uses(e,B_w)}
 {B_w;T\vdash\mathsf{if}\ e\triangleright([],R)}

\Rule{D-Bind}{\bar N=\binds(p)\quad R=\uses(e,B_w)}
 {B_w;T\vdash\mathsf{let}\ p[:\tau]=e\triangleright(\bar N,R)}
\end{mathpar}
Extend $B_w$ by each provided list. Identities and central comparisons
require their query variables and provide none. A Rust-free block provides
its free/interface heading; a Rust block requires its free names and provides
its interface. For pending indices $U$ and currently bound $B$, readiness is:
\[
\Rule{C-Ready}{i\in U\quad R_i\subseteq B\\
 \neg\mathsf{Rust}(c_i)\ \lor\
 (i=\min\{j\in U\mid\mathsf{Rust}(c_j)\}\land
  \operatorname{Before}(i)\cap U=\emptyset)}
 {U;B\vdash i:\mathsf{ready}}.
\]
Here Before includes every earlier atom/block and relational identity or
constraint, and Rust includes pinned blocks. Guards and lets share one chain.
Prefix and Elimination repeatedly
choose the least rank among ready clauses, remove that clause from $U$, and
extend $B$ by its provided names; an empty ready set is an error. Written
instead takes the body sequence directly. Write $O_i=\set(\bar O_i)$ and
let $\kappa$ map names to their relational equality-class representatives.
For Prefix set $s_i=|\kappa(O_i)\cap\kappa(B)|$; Boolean ranks order false
before true.
\begin{mathpar}

\Rule{S-Written}{}{\mathsf{sequence}_{Written}(q)=[0,\ldots,m-1]}

\Rule{S-Connected}{c_i\text{ atom}\quad s_i=|\kappa(O_i)\cap\kappa(B)|}
 {\mathsf{rank}_{Connected}(i,B)=(1,[s_i=0],0,i)}

\Rule{S-Greedy}{c_i\text{ atom}\quad s_i=|\kappa(O_i)\cap\kappa(B)|\\
 r\in\{GreedyWidth,Auto\}}
 {\mathsf{rank}_{r}(i,B)=(1,[s_i=0],|\kappa(B)\cup\kappa(O_i)|,i)}

\Rule{S-Elimination}{c_i\text{ atom}\quad E=\mathsf{analysis}(q).\mathit{elimination\_order}\\
 e_i=\min(\{\operatorname{pos}_E(x)\mid x\in O_i\}\cup\{|E|\})}
 {\mathsf{rank}_{Elimination}(i,B)=(1,0,e_i,i)}
\end{mathpar}
Ready central constraints rank $(0,0,0,i)$; other nonatoms rank
$(0,0,1,i)$. Prefix connectivity and width use relational equality classes,
so aliases count as one available variable.
Auto is exactly GreedyWidth. Elimination uses reverse maximum-cardinality
search numbering of the atom primal graph; it need not require acyclicity.
An atom variable absent from that numbering is diagnosed.

\paragraph{Coarse and Fine.}
Coarse follows the chosen sequence and emits one full subatom per atom,
copying identities, constraints and Rust steps. Written/Fine splits each atom
in place in its declared argument order, preserving the complete NF clause
sequence; an atom introducing nothing remains one full check. For optimized
Fine, variable order follows first provision along the selected sequence,
except Elimination reverses $E$; aliases are grouped by their earliest supplier.
The rules below describe optimized Fine, subject to the unified Rust chain,
Before and complete-row checks.
\begin{mathpar}

\Rule{O-Coarse}{\mathit{seq}\text{ chosen}}
 {\mathsf{coarse}(\mathit{seq})=[\mathsf{fullSubatom}(i)\text{ or the copied central/Rust step}\mid i\in\mathit{seq}]}

\Rule{O-Fine}{(G_0,B_0)=\mathsf{flush}(B)\quad v\text{ first eligible remaining variable}\\
 (a,G_1,B_1,J)=\mathsf{introduce}(v,B_0)}
 {\mathsf{fineStep}(v,B)=G_0\concat a\concat G_1
   \concat[\mathsf{subatom}(j,B_1)]_{j\in J}}
\end{mathpar}
In O-Fine, $\mathsf{flush}$ repeatedly chooses a ready waiting step,
prioritizing central constraints and then source index. Pending incomplete
atoms count toward Before until their full correlated rows have been checked.
It emits each step and adds its provided names. A variable is eligible if no
Rust step supplies it or it is already bound. Let $I_v$ be its holding atom indices in chosen clause order.
If $v\notin B_0$, $\mathsf{introduce}$ adds $v$, emits subatom $a$ of the first
holding atom over $B_0\cup\{v\}$, flushes again to obtain $(G_1,B_1)$, and leaves
$J$ as the remaining holding atoms. Otherwise $a,G_1$ are empty, $B_1=B_0$, and
$J=I_v$. Each subatom lists the clause's currently bound columns and drops the
others. A final flush follows all variables. Lets can bind several names.
If every remaining variable waits for an unavailable let, compilation fails. The final VO contract is always checked. Declared CQ
relations have positive arity.

\subsection{Hypergraph facts and GYO}
\label{sec:graph-extraction}\label{sec:gyo-construction}
For one NF body, let $O$ include its atom occurrences and Rust-free blocks.
Store each ordered heading $\bar X_i$; a block uses its free/interface heading.
Write $X_i=\set(\bar X_i)$ for the actual heading; graph edges
$\widehat X_i$ expand it by the relational variable equality classes. These classes include variable identities/recognized
equalities, not literals or opaque Rust. Branch bodies are analyzed separately.
\begin{mathpar}

\Rule{H-Occurrence}{q.body_i=R(\bar x)\text{ or a Rust-free block with heading }\bar x}
 {\mathsf{clauses}(q)[i]=\bar x}

\Rule{H-Incidence}{i\in O\quad x\in\widehat X_i}
 {i\in\mathsf{incidence}(q)[x]}

\Rule{H-Adjacency}{i<j\quad S_{ij}=\widehat X_i\cap\widehat X_j\ne\emptyset}
 {i\xleftrightarrow{S_{ij}}j}
\end{mathpar}
H-Adjacency is an abstract derived view, not another IR. The primal graph
connects equality-related variables and variables sharing an expanded edge.
Opaque guards, lets and Rust-containing blocks add no hyperedges. Occurrence
identities preserve repeated and empty edges; identifying duplicate nonempty
edges gives the usual unlabelled hypergraph.

GYO starts with residual sets $Z(i)=\widehat X_i$ and parents $\pi(i)=\bot$.
Original clause facts remain unchanged. It first chooses the lexicographically
least private pair $(i,x)$, or, if none exists, the least absorb pair $(i,j)$:
\begin{mathpar}

\Rule{G-Private}{i\in\dom Z\quad x\in Z(i)\quad\forall j\in\dom Z\setminus\{i\}.\ x\notin Z(j)}
 {(Z,\pi)\longrightarrow(Z[i\mapsto Z(i)\setminus\{x\}],\pi)}

\Rule{G-Absorb}{i,j\in\dom Z\quad i\ne j\quad Z(i)\subseteq Z(j)}
 {(Z,\pi)\longrightarrow(Z\setminus\{i\},\pi[i\mapsto j])}

\Rule{G-Accept}{Z\text{ terminal}\quad |\dom Z|\le1\quad\forall i\in\dom Z.\ Z(i)=\emptyset}
 {(Z,\pi)\Downarrow\mathsf{acyclic}=true}

\Rule{G-Reject}{Z\text{ terminal}\quad\neg(|\dom Z|\le1\land\forall i\in\dom Z.\ Z(i)=\emptyset)}
 {(Z,\pi)\Downarrow\mathsf{acyclic}=false}

\Rule{H-JoinTree}{\mathsf{acyclic}=true}
 {\mathsf{join\_tree}=\mathsf{Some}([(i,\pi(i))]_{i\in O\text{ increasing}})}
\end{mathpar}
Each deletion is also recorded as a \code{GyoStep}. On the admitted nonempty
atom domain, acceptance leaves exactly one empty residual edge. Failure gives
\code{join_tree = None}. H-JoinTree returns the constructed parent map; it is
not an independent running-intersection test.

\begin{theorem}[Abstract GYO recognition]
GYO terminates and accepts exactly the occurrence hypergraphs admitting a join
tree. Its successful parent map has running intersection on original edges.
\end{theorem}
\begin{proof}
$|\dom Z|+\sum_i|Z(i)|$ strictly decreases. While two active original edges
contain $x$, neither can first remove $x$ as private. Hence an absorption's
shared original variables lie in its container, making it an ear removal.
Private deletion and absorption preserve join-tree existence. Conversely, a
leaf of a join tree either has a private variable or is contained in its
neighbour. Thus a nonempty acyclic terminal state is one empty edge. Reversing
absorptions attaches each deleted edge to its recorded parent and preserves
running intersection, including duplicate and empty edges.
\end{proof}

\subsection{Reduction as VO steps}
\label{sec:yannakakis}
The reducer checks source VO and rejects an already reduced source.
\code{Pushdown::None} and the compatibility spelling \code{Pushdown::Atoms}
both leave opaque Rust guards in their original chain:
\[
\Rule{R-Guard}{\mathsf{step}=\mathsf{Guard}(e)}
 {\mathsf{reduce}(\mathsf{step})=\mathsf{step}}.
\]
Central comparisons are handled by ordering and elaboration, not guard
reductions.

With \code{Reductions::Tree}, obtain the GYO
join tree or diagnose cyclic input.

Let $B=[o,b_1,\ldots,b_{n-1}]$ be its BFS
order, children appended in increasing clause-index order. Define
$\mathsf{red}(i,j)$ as \code{reduce} of $i$ with a subatom of $j$ listing exactly
the names of $j$ whose equality class also occurs in $i$, in $j$'s column
positions and underscores elsewhere.
\begin{mathpar}

\Rule{Y-Up}{B=\mathsf{BFS}(J)}
 {\mathsf{up}(J)=[\mathsf{red}(\pi(b),b)\mid b\in\mathsf{reverse}(B[1..])]}

\Rule{Y-Down}{B=\mathsf{BFS}(J)}
 {\mathsf{down}(J)=[\mathsf{red}(b,\pi(b))\mid b\in B[1..]]}

\Rule{R-Tree}{J=\mathsf{analysis}(q).\mathsf{join\_tree}\ne\mathsf{None}}
 {\mathsf{Tree}(VO)=\mathsf{insertAtReadyPrefix}(VO,\mathsf{up}(J)\concat\mathsf{down}(J))}
\end{mathpar}
The insertion point is the first atom/block by default; when a finite domain
requires written Rust bindings, it is the earliest prefix providing all of
those bindings. None copies the source schedule. Hypergraph uses the tree reducer when
acyclic and also cuts every surrounding atom sharing columns with a Rust-free
block through that derived relation, even on cyclic inputs. Reductions recurse
into branch schedules and retain fixed paths. If a block's finite domain
requires prefix Rust values, reductions wait for those bindings. Elaboration
filters an already-read target's retained prefix rather than replacing an
independent earlier row. Positive cuts may distribute into arms; negative
originals remain unchanged.

\begin{theorem}[Abstract full-reducer law]
For finite relations $L_i:X_i$ on a join tree (headings interpreted modulo
relational identity), upward reverse-BFS and downward
BFS semijoins preserve $Q=\bowtie_i L_i$ and leave each relation equal to
$\pi_{X_i}Q$. There are $2(n-1)$ semijoin steps.
\end{theorem}
\begin{proof}
For child $c$, running intersection makes the separator $S_c=X_c\cap X_{\pi(c)}$
exactly the variables crossing its subtree cut. After upward reduction, the
relation at $i$ is $\pi_{X_i}(\bowtie_{j\in T_i}L_j)$: completed children supply
compatible subtree witnesses through their whole separators. The root therefore
has complete support. In the downward sweep a surviving child tuple matches a
globally supported parent tuple. Its subtree witness and the parent's outside
witness agree on $S_c$, so they combine into a full witness. Every full witness
survives every semijoin. Empty separators test nonemptiness; the one-node case
needs no steps. Central relational selections may be included in $L_i$. Opaque Rust guards
remain in the VO chain and are not covered by this total relational theorem.
\end{proof}

\subsection{Elaboration: VO to named RA}
The state $(D,M,p,B)$ contains emitted definitions, the latest relation name per
atom clause, an optional prefix, and its bound heading. All start empty.
\begin{mathpar}

\Rule{E-Emit}{r=\text{next unused }\code{rN}\text{ in emission order}}
 {\emit(D,o)=(D\concat[r=o],r)}

\Rule{E-Relation}{i\notin\dom M\quad m_i\text{ maps declared columns positionally to }\bar X_i\\
 (D',r)=\emit(D,\delta_{m_i}(R_i@i))}
 {\mathsf{relation}(i;D,M)=(D',M[i\mapsto r],r)}
\end{mathpar}
An existing $M(i)$ is returned unchanged. Relations are emitted lazily at
first mention, whether by reduction or subatom, but their occurrence paths
remain their NF clause identities. Emitted result names skip reserved input
relation names. In flat optimized elaboration, alias solving uses relational
variable identities while protecting head names and let-supplied names;
central constraints/identities may be attached to complete earlier binder
occurrences. Block elaboration uses explicit scopes and branch paths. The following rules use
$\mathsf{relation}$ implicitly to obtain $r=M(i)$, and $K$ for the subatom's
listed variables. The source VO contract supplies positional correctness and
\code{introduces}. Full means no dropped column.
\begin{mathpar}

\Rule{E-Check}{K\subsetneq X_i\quad\mathsf{introduces}=\emptyset\quad p\ne\bot}
 {(D,M,p,B)\xrightarrow{i,K}(D',M,s,B)\quad[(D',s)=\emit(D,p\ltimes r)]}

\Rule{E-Project}{K\subsetneq X_i\quad\neg(\mathsf{introduces}=\emptyset\land p\ne\bot)\\
 (D',s)=\emit(D,\pi_Kr)}
 {\mathsf{subatomRight}(i,K)=(D',s)}

\Rule{B-Root}{p=\bot\quad s=\mathsf{subatomRight}(i,K)}
 {(D,M,p,B)\xrightarrow{i,K}(D,M,s,B\cup K)}

\Rule{B-Join}{p\ne\bot\quad\text{E-Check inapplicable}\quad s=\mathsf{subatomRight}(i,K)\\
 (D',t)=\emit(D,p\bowtie s)}
 {(D,M,p,B)\xrightarrow{i,K}(D',M,t,B\cup K)}
\end{mathpar}
For full subatoms, $\mathsf{subatomRight}(i,X_i)=M(i)$ without projection.
In B-Root/B-Join, $D,M$ already include any relation/projection emissions.
A full subatom always joins even when it introduces no new variable. A partial
check uses the full current clause relation: VO ensures its heading intersection
with $B$ is exactly $K$.

Let $\mathsf{unitize}$ return $p$ or emit Unit if absent. A VO guard
appends an opaque Rust guard to that prefix. A let extends it with its pattern binders and symbolic types, using
\code{binding_types()} (including Rust inference placeholders).
\begin{mathpar}

\Rule{C-Guard}{\mathsf{step}=\mathsf{Guard}(e)\quad p_0=\mathsf{unitize}(p)\\
 (D',s)=\emit(D,\operatorname{guard}_e p_0)}
 {(D,M,p,B)\longrightarrow(D',M,s,B)}

\Rule{C-Bind}{\mathsf{step}=\mathsf{Let}(pat[:\tau]=e)\quad\bar N=\binds(pat)\\
 p_0=\mathsf{unitize}(p)\quad(D',s)=\emit(D,\operatorname{bind}_{pat[:\tau],e}p_0)}
 {(D,M,p,B)\longrightarrow(D',M,s,B\cup\set(\bar N))}

\Rule{E-ReduceWith}{\mathsf{step}=\mathsf{reduce}\ i\ \mathsf{with}\ j\\
 (D',s)=\emit(D,M(i)\ltimes_{\equiv}M(j))}
 {(D,M,p,B)\longrightarrow(D',M[i\mapsto s],p,B)}
\end{mathpar}
Relation lookup and unitization emissions precede the displayed emissions.
Bind copies the original pattern, annotation and expression, including
patterns with no binders; no tuple-returning wrapper is inserted. Scoped
Rust also records its written lexical environment and path. In E-ReduceWith,
$\ltimes_{\equiv}$ matches every listed support column with the target
equality class. If protected Rust/head names prevent alias renaming,
elaboration realizes this as join/select/project rather than natural
semijoin alone. The target clause is updated; an already-read target also
filters the retained prefix. VO checks the full support key.
After all checked VO steps, project to the variable-only NF head names
$W$. Computed heads have already become Rust bindings:
\[
\Rule{C-Finish}{\text{all VO steps consumed}\\
 p_0=\mathsf{unitize}(p)\quad(D',r)=\emit(D,\pi_Wp_0)}
 {(D,M,p,B)\Downarrow(D',\mathsf{output}\ r\ \mathsf{as}\ h(\bar e))}.
\]
The complete RA result owns the CQ declarations, $D'$ and output. The constructor
then checks the RA contract. It returns no CQ annotation or planning report.

\subsection{Abstract retention and set laws}
\label{sec:join-order}\label{sec:retention}\label{sec:join-arity}
For disjoint occurrence groups $C,E$, a ghost binary tree over full atoms can
witness coarse join assembly; it is mathematical notation, not stored IR.
\begin{mathpar}

\Rule{O-Leaf}{i\in O}{i:\{i\}}

\Rule{O-Join}{T_1:C\quad T_2:E\quad C\cap E=\emptyset}
 {(T_1\bowtie T_2):C\cup E}

\Rule{L-Retention}{L:V\quad M:W\quad V\cap(W\cup H\cup\fv(P))\subseteq U\subseteq V}
 {\pi_H\sigma_P(L\bowtie M)=\pi_H\sigma_P(\pi_U L\bowtie M)}
\end{mathpar}
All three rules here are abstract. Retention follows by restricting a left
witness in one direction and choosing its original witness in the other; all
shared or free-variable coordinates survive. In occurrence notation its required
sort is $K(C,P)=X(C)\cap(H\cup X(O\setminus C)\cup\fv(P))$.
This law describes potential general last-use pruning. The elaborator
projects partial subatoms, block interfaces/domains, reduction support and
the final head; it does not search for arbitrary subtree pruning. Structures
also records checked filtered payload projections. Projection and joins here
have finite-set semantics; the law does not preserve arbitrary callback counts.

Heading arity $|V|$, row cardinality $|\sem r_I|$, physical bytes and elimination
width are different measures. An abstract row-volume proxy is
$W_0(D,I)=\sum_{r=l\bowtie s\in D}|\sem r_I|$.
It is not a runtime statistic or an optimality guarantee. Fine variable-at-a-time
planning is implemented; this paper establishes no WCOJ complexity bound.

\subsection{Facade compositions}
Let $N$ be normalization, $O_{h,s}$ ordering, $R_{g,r}$ reduction and $E$
elaboration. Each expression below means fallible composition of constructors.
\begin{mathpar}

\Rule{Plan-Prefix}{n=N(q)\quad v=O_{Written,Coarse}(n)\quad a=E(v)}
 {\code{mini_linq::passes::plan_written}(q)=a}

\Rule{Plan-Generic}{n=N(q)\quad v=O_{Written,Fine}(n)\quad a=E(v)}
 {\code{cq_planners::order(written, fine)}(q)=a}

\Rule{Plan-Graph}{n=N(q)\quad v=O_{Written,Coarse}(n)\\
 r=\text{Hypergraph if blocks; otherwise Tree if acyclic, else None}\\
 w=R_{None,r}(v)\quad a=E(w)}
 {\code{cq_planners::order(hypergraph)}(q)=a}
\end{mathpar}
The default planner belongs to the core facade; Generic and Graph are choices
of the external \code{cq-planners} consumer. The caller selects its path and
arguments in \code{pipeline { plan = Path(tokens); }}. Each composition checks
its logical pass boundaries and returns a complete RA program to the next
queued macro, normally \code{mini_linq::passes::index_demands}. Arguments choose
the recorded VO schedule; later passes consume the resulting RA graph.
