\section{Structures: concrete representations}
\label{sec:structures}

\paragraph{Grammar.} Structures extends a complete Physical program.
\begin{lstlisting}
Structures ::= Physical structures { Entry* }
Entry ::= r = Type [K]... [membership] [payload[P] constants{c = term, ...}];
        | r host reader = Type [K]...;
        | r rows = Type; | r canon = Type; | r head = Type;
        | r selection = Type base H lineage{a -> c, ...}
              summary (none | per_block);
        | r keyset = Type [K] (owned | borrowed)
              base H lineage{a -> c, ...};
        | r read = positional base H lineage{a -> c, ...}
              column c marker Type predicate Predicate;
        | r join_filter = Type build s [k]
              covering j marker Type;
        | r share = lookup b [K] first s force p;
        | r repr = (tuples | positions {H lineage {a -> c, ...}, ...}
                         owned [O]) [witness {b [K] at s as Type}];
        | r stage = batch N [expand];
Predicate ::= physical | membership s [K] summary (exact | row)
\end{lstlisting}

\paragraph{Contract.} $\mathsf{Entries}(t,A)$ checks the embedded Physical and:
(1)~built columns belong to the heading and never repeat across levels; a built
key answers a union of a prefix of its levels;
(2)~host entries record fallback types per reader, not native trait claims;
(3)~retained scans, multiple unfiltered builds and exists state record row
storage; host renames record scan and keyed-reader fallbacks;
(4)~every definition canon has a dedup entry; \code{return canon} has a head
dedup entry; computed heads that may collapse valuations have one too;
(5)~filtered entries (point/range selections or unions only) record one shared
projection; their readers are stream \code{probe first}, semi or anti on a level
prefix; payload plus the singleton constants proved by the selection cover all
downstream keys, predicates, Rust free variables and answers. Constant columns
are reconstructed, not stored;
(6)~selection, keyset and read entries independently rederive a single declared
host occurrence and a total, injective logical-to-host mapping over the reader's
heading. Rename, declarative selection, occurrence-preserving projection and
the left of eager semi propagate lineage. Computed columns, bind, opaque guard,
join expansion, canon, union/fallback/anti and fused branch scopes do not;
(7)~a selection replaces a retained tuple collection, never a key-only,
ordered or candidate provider. Every filtering step down to a prior immutable
snapshot has an explicit read; an unrecorded retained result cannot be bypassed;
(8)~a positional read refers only to its existing point/range predicate or its
own eager semi's strictly earlier RHS build. These exact read entries cannot
form summary cycles or name nonlocal probe filters. Exact summary requires
an owned scalar keyset and \code{ExactIntervalMembership}; row summary uses exact membership alone;
(9)~keysets record their concrete provider, ownership, codec and const bitmap
budget. The initial owned layout is one \code{i64}; borrowed layouts are tuples.
Known codecs must match that layout. Payload indexes may coexist with keysets.
The default \code{ColumnAt<N>} marker must match declaration-order column $N$.
Rust additionally checks positional host, marker, key, lifetime and provider
obligations; a trait implementation must obey the storage abstraction laws.
\begin{mathpar}
\Rule{STR-Lineage}{\mathsf{singleOccurrenceSpine}(r,H)\quad
 \lambda:\mathsf{heading}(r)\hookrightarrow\mathsf{columns}(H)}
 {\mathsf{lineage}(r)=(H,\lambda)}

\Rule{STR-Read}{r=\mathsf{semi}_{eager}[K](l,s)\quad s<r\quad
 \mathsf{keyset}(s,K)\quad\mathsf{lineage}(r)=(H,\lambda)}
 {r\;\mathsf{read}(H,\lambda(K),\mathsf{membership}(s,K))\text{ is admissible}}

\Rule{STR-Key}{\mathsf{hostRead}(r)\lor\mathsf{built}(r,C)}
 {\mathsf{answers}(r,C,probe/semi)}

\Rule{STR-Keyset}{\mathsf{keyset}(r,K)\quad
 \mathsf{reusableRows}(r)\quad T:\code{ExactMembership}(K)}
 {\mathsf{answers}(r,K,semi/anti)\text{ independently of payload indexes}}

\Rule{STR-Existential}{\mathsf{filtered}(r,P,C)\quad P\subseteq K\\
 \mathsf{readKeys}(r)=\{K\}\quad \mathsf{reads}(r)\subseteq\{probe\ first,semi,anti\}}
 {\mathsf{membershipBuild}(r,K)\text{ replaces witness enumeration by existence}}

\Rule{STR-Range}{\text{constant window on }r,c}
 {\mathsf{answers}(r,\{c\},range)\text{ by direct range or scan/filter; no build}}

\Rule{STR-Merge}{\mathsf{hostRead}(r)\lor\mathsf{built}(r,C)\\
 \text{or }(\mathsf{mode}(r)=pipe\land\mathsf{operator}(r)=merge[C](l,s))}
 {\mathsf{answers}(r,C,merge)}

\Rule{WF-Structures}{\mathsf{Entries}(t,A)\quad\text{all Physical reads answered}\\
 \mathsf{unique}(t.returned)\text{ inferred or explicit return canon}}
 {\mathsf{WF}_{Structures}(t)\Downarrow A}
\end{mathpar}
Uniqueness: Unit has the empty key; a rename of a certified \code{host_set}
has its full heading as key, and other host renames have none; join needs both
keys and unions them; semi/anti keep the left key; union infers none;
selections, guards and binds preserve it; projection preserves it only if no key
column is dropped; a canon flag gives the full heading through its dedup type.
A built structure alone proves no uniqueness.
An explicit \code{membership} modifier on a single-level filtered build proves
that every downstream observation is a supplied key or reconstructed constant.
The checker rederives projection coverage and rejects partial-key or ordered
reads. The printer emits one unit witness on successful membership, without an
occurrence-preserving payload index. The default integral-key representation is
\code{AdaptiveKeySet} with its recorded borrowed codec and bitmap bound.
No base-table key or foreign-key assumption is used.

\paragraph{Sorted runs.}
\code{SortedRun} stably clusters payload occurrences by key. Its directory
and adjacent offsets partition a contiguous payload array; lookup returns a
Copy range cursor. Equal-key input order and multiplicity are preserved.
Presence/rank and binary-search directory access identify the same exact
range. This is a payload representation, not a uniqueness assertion.
\begin{mathpar}
\Rule{STR-SortedRun}{
 \mathsf{stableCluster}(I,K)=(D,O,V)\quad
 \mathsf{exactDirectory}(D,O)
}{\mathsf{lookup}(k)=I|_{K=k}\quad \alpha(D,O,V)=\mathsf{bag}(I)}

\Rule{EXT-SortedRuns}{
 \mathsf{oneLevelHashPayload}(b,K)\quad
 \mathsf{borrowedIntegralKey}(K)\quad\mathsf{streamReads}(b)
}{\mathsf{retype}(b,\mathsf{SortedRun})\text{ preserves Structures}}

\Rule{EXT-SortedIndexes}{
 \mathcal{K}=\{K\mid \mathsf{streamRead}(b,K)\}\quad
 \mathsf{integralKeys}(\mathcal{K})\quad
 \mathcal{C}=\mathsf{minChainCover}(\mathcal{K})\ \text{with probed keys maximal}\\
 \text{each chain's levels ordered by first binding in the reading stream}
}{\mathsf{layouts}(b,\mathcal{C})\text{ preserves Physical and Structures}}
\end{mathpar}
The external sorted-runs rewrite changes only eligible built providers,
not host fallbacks or smallest-intersection candidate providers. Its
independent checker preserves Physical and rederives coverage.
The sorted-indexes rewrite records which lexicographic layouts serve a built
result's probe and semijoin reads: a fewest set of chains of read keys, each
recorded as singleton levels. A key read by a payload probe ends its chain,
since a payload probe reads all built levels. An explicit
\code{Rel => [a][b]} choice replaces the default layout of one result and
must serve every read. It decides no canonical (dedup or maintenance) layout
and no representation type beyond the defaults that \code{sorted\_runs} and
\code{prefix\_runs} then retype.

\paragraph{Meaning.} That of the embedded Physical. Each Rust type is a
representation whose abstraction function $\alpha$ satisfies the
\code{cq-storage} laws: $\alpha(\mathsf{build}(I))=\mathrm{bag}(I)$, lookups
enumerate exactly the matching items, membership is exact. Rust checks the trait
bounds at generated uses; the laws are tested, not derived.

\paragraph{Recorded decisions.} Every concrete type: built indexes and levels,
per-reader host fallbacks, retained rows, dedup state, filtered payloads and
constants, positional bases and column lineage, mask-summary policy, column
markers, keyset ownership/codec/budget and exact versus row-only read summaries.
Positions identify base occurrences without becoming logical columns. A selection
is not Canonical or OrderedRead. Nothing is substituted at print time.

\paragraph{Default hash representations.} Selection records
\code{::cq_storage::HashSet<_>} for built membership, canonicalization and
head deduplication. This alias names
\code{std::collections::HashSet<K, cq_storage::HashState>};
\code{HashState} uses keyed aHash. Payload reads record
\code{::cq_storage::HashIndex<'_,_,_>}; its definition uses the same fast
hash state. A deferred host membership fallback records
\code{::cq_storage::dispatch::KeySet<_>} (or the lazy \code{false} form),
whose key set uses that state. Trie levels and the staging and hash forms of
\code{AdaptiveKeySet} likewise fix their hash representation in the named
runtime type. The printer emits recorded type tokens directly; retyping to
\code{std::collections::HashSet<_>} retains the standard hasher.
Dedup construction imports \code{HashSetConstructor} for hash sets with an
explicit state, preserving the existing \code{new()} protocol and inherent
constructors of custom providers. It does not replace a recorded type.
Counter builds retain their deterministic measurement collections and fixed
seeds; their hash-finish counts cover runtime internal collections, not every
canonicalization or host hash operation.

\code{HashIndex} stores exact keys and arena slots in a hashbrown Swiss table
using the recorded keyed hash state, plus a contiguous arena of first payloads.
Hash collisions always require full key equality.
Only keys with additional occurrences allocate a shared tail.
Initialization consumes the source once, on first access, and is shared by
cloned handles. A standalone lookup cursor copies the first payload and owns
its tail; it survives dropping the index and advances independently.
Membership tests the directory directly, without constructing a cursor.
The \code{IndexRead::probe<N>} protocol has a scalar default and preserves outer
order, within-bucket source order and bag multiplicity. \code{HashIndex} realizes
\code{N=128} by hashing all keys, prefetching candidate buckets, then resolving
exact matches; \code{N=1} retains scalar demand with no lookahead or prefetch.
Both retain one index handle per stream and enumerate payloads without per-row
reference-count operations. An empty outer stream does not initialize the index.
For single-level probes over borrowed rows, the staging pass records the former
fixed lookahead as \code{stage = batch 128} on a total host scan spine
(rename, relational select/point/range and projection).
Section~\ref{sec:backend} gives the checked evaluation-unit decision; absent
stage entries mean scalar demand. Already-reduced/joined streams, opaque guards
and branches retain scalar demand by default; computed rows and curried access
retain their existing lookup protocol. The printer consumes the recorded
decision. No runtime statistics or adaptive choice is used, and bounded
lookahead cannot force an unvisited partial Rust expression.
Candidate counts remain exact occurrence counts (upper bounds for distinct
candidate enumeration), without enumerating a bucket. Retained-capacity
counters account for the directory, arena and live tail buffers separately.

\paragraph{Rewrite check (\code{cq_lang_structures::check_rewrite}).} Both local
contracts hold and the embedded Physical AST and token serialization are exactly
equal. Lineage, read coverage and summary obligations are rederived independently.
Retype selectors \code{kind(selection)} and \code{kind(keyset)} preserve origin,
levels and policy; \code{rows} still selects FromIterator buffers. Membership
includes keysets. Losing interval membership requires an explicit row-summary
rewrite or rejection, never a printer fallback.

\paragraph{Covered join filters.}
An entry \code{s join_filter = Type build b [k] covering j
marker ::cq_load::ColumnAt<n>;} records a structure's Rust type, the scan
occurrence, the filtered key column, host key column and exact covering
operator. A scan may carry several entries, one per covering operator and key
column. The core neither classifies approximate algorithms nor recognizes their names.
\textsc{STR-JoinFilter} independently checks that \code{j} is an eager probe or
semijoin of \code{b} on a key $K\ni k$ served by one single-level hash index,
that the build is total, and that the scan reaches \code{j} through an
exclusive pipe spine whose every result carries $k$: renames, projections,
declarative selections and left operands of eager probes and semijoins.
Rows of the scan with $k\notin\pi_k(b)$ produce, along that spine, only rows
with the same $k$, which \code{j} drops; so the filter keeps a superset of the
rows \code{j} can keep ($R\ltimes b\subseteq\sigma_F(R)\subseteq R$). A key bound
only by an intermediate build is not a scan column and is rejected.
Retained, scoped, opaque and occurrence-expanding boundaries other than those
left operands are rejected. An anti join cannot cover
a filter. Removing the exact operator leaves an invalid entry: a conservative
filter can never be the only check of the constraint.

For the keys $S$ supplied by \code{Build}, the capability laws are
\[
 \begin{aligned}
 T:\code{ConservativeMembership<K>} &: \quad k\in S\implies T.\mathsf{test}(k),\\
 T:\code{ExactMembership<K>} &: \quad k\in S\iff T.\mathsf{contains}(k).
 \end{aligned}
\]
Every exact type also implements conservative membership by a blanket
implementation. Neither capability is a uniqueness proof. Runtime weakening
to an always-true test is permitted by the one-sided law; false negatives are
never permitted. A conservative \code{may_contain_in(lo,hi)} may return false only
when the closed interval contains no build key. Its default retains every
block; the exact-to-conservative blanket uses this default. Missing host block
metadata also retains the block. Exact keyset reads retain their separate
\code{ExactIntervalMembership} capability. Rustc checks capabilities through
\code{require::conservative::<K,T>}; semantic provider laws remain premises.
External structures may supply stronger block summaries without changing the
covering obligation. False positives are eliminated by the unchanged probe.
For a positional static read directly over the rename/project spine, realization
intersects both block summaries and tests the static row predicate before the
join key. The optional counters \code{join_filter_tested} and
\code{join_filter_passed} measure that key-filter boundary; subsequent residual
conditions and relational readers can reduce the surviving count further.
\begin{mathpar}
\Rule{STR-JoinFilter}{
 j\in\{\mathsf{probe}[K](l,b),\mathsf{semi}[K](l,b)\}\ \text{eager}\quad
 k\in K\quad k:\code{i64}\quad
 \mathsf{exactKeyIndex}(b,K)\in\{\code{HashIndex},\code{SortedRun}\}\\
 \mathsf{exclusiveSpine}_k(s,l)\quad
 \mathsf{totalBuild}(b)\quad
 \mathsf{marker}(s,k)=C\\
 T:\code{Build}\quad T:\code{ConservativeMembership}(k)\quad
 \pi_k(b)\subseteq\{x\mid F.\mathsf{test}(x)\}
}{
 s\;\mathsf{joinFilter}(F,b,k,j,C)\text{ is admissible}
}
\end{mathpar}
Here $\mathsf{exclusiveSpine}_k$ contains only one-use pipe renames,
projections, declarative selections and left operands of eager probes and
semijoins, each carrying $k$, without canon or fused scopes; the scan's
lineage maps $k$ to a host column.
Both admitted payload providers enumerate their exact distinct keys for filter
construction. Retyping a hash build to a sorted run preserves this premise.
A retained-cursor probe remains an exact covering read: its earlier eager
semi performed the same-key lookup. The original covering operator and its
exclusive-spine proof are retained, not redirected across an opaque Rust or
canonical boundary.
The recorded type is checked syntactically as a Rust type, and its capabilities
are checked by rustc, rather than by a provider-name whitelist. External
\code{retype(s join_filter => T)} changes only the recorded types of that scan.
\code{join_filter(s)} may explicitly add default exact structures for every
admissible covering operator of \code{s} not yet recorded (including total
unfiltered builds); it records positional-host advice and undergoes the same
contract and correspondence checks.
