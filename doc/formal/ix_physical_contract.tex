\section{IX: required indexes and exact uses}
\label{sec:ix}
Between RA and physical selection, IX records which attribute-keyed accesses
the fixed plan demands and which operator position uses each one. It performs
no data-structure selection and emits no runtime construction. The compiled
chain continues
\[
 \mathrm{RA}\longrightarrow\mathrm{IX}
 \xrightarrow{\text{policy}}\mathrm{Physical}
 \xrightarrow{\text{policy}}\mathrm{Structures}
 \longrightarrow\mathrm{Rust},
\]
where the two policy steps are caller-resolved macro slots
(\code{physical_policy!} and \code{select_structures!}).

\paragraph{Boundary syntax.}
Let $r,l$ name exact RA versions, $j$ an operator occurrence, $i$ an index,
and $C$ an ordered list of logical column ordinals. For the present binary
fragment, $p=j.\mathsf{right}$ is the indexed operand of $j=l\bowtie r$ or
$j=l\ltimes r$.
\begin{lstlisting}
IX  ::= RA indexes { Def* } uses { Use* }
Def ::= i = @r[C];
Use ::= j.right = i;
\end{lstlisting}
IX retains RA unchanged. The listing is the fragment used below; the complete
grammar is in \path{doc/DSL.md}.

\paragraph{IX meaning and construction.}
Write IX as $(A,D,U)$, with $D:i\mapsto(r,C)$ and $U:p\mapsto i$.
Well-formedness requires well-formed RA, unique descriptors, valid ordered
columns, and exactly one use reference for every admitted indexed position.
Each use names its exact operand version and RA join columns; there are no unused
index definitions. Erasure preserves meaning:
$\sem{A,D,U}_{IX}=\sem A_{RA}$.
Traverse the fixed RA definitions in order, starting with empty $D,U$:
\begin{mathpar}
\Rule{IX-Reuse}{D(i)=(r,C)}{D\vdash(r,C)\Downarrow(i,D)}

\Rule{IX-New}{(r,C)\notin\operatorname{ran}D\quad i=i_{|D|}}
 {D\vdash(r,C)\Downarrow(i,D[i\mapsto(r,C)])}

\Rule{IX-Join}{o\in\{\bowtie,\ltimes\}\quad
 C=[c\mid 0\leq c<|H(r)|,\ H(r)_c\in H(l)]_{\rm increasing}\\
 D\vdash(r,C)\Downarrow(i,D')}
 {(D,U)\vdash j=l\mathbin{o}r\Downarrow(D',U[j.\mathsf{right}\mapsto i])}

\Rule{IX-Other}{d\in\{\mathsf{Unit,Rename,Project,Select,Extend}\}}
 {(D,U)\vdash d\Downarrow(D,U)}
\end{mathpar}
Fresh $i_n$ prints as \code{i0}, \code{i1}, etc. Unknown operators reject.
$C=[]$ is the unit tuple for the admitted Cartesian case. Physical lowering
consumes written $D,U$; it does not repeat this analysis. This binary fragment
does not yet specify the index demands or planning of WCOJ.

\paragraph{Physical and Structures.}
Physical restates every IX result with one physical operator (probe, merge,
semi, range, or the logical operator's own name) and the mode its reads allow
(pipe, let, alias), marking canonical results; Structures binds every keyed
read to a host key fact or a Rust type built over the result and discharges the
order and canonical premises. Below Structures a printer emits one pull program
over the \code{cq-storage} operation traits. These languages have no formal
treatment in this paper yet; their syntax, contracts and laws are specified by
the module documentation of \path{crates/cq-ir/src/physical.rs},
\path{crates/cq-ir/src/structures.rs}, \path{crates/cq-ir/src/policy.rs}, and
by \path{doc/DSL.md}, until a formal treatment is written.
