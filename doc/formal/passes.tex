\section{Passes}
\label{sec:passes}\label{sec:planning}\label{sec:pass-contracts}
Each subsection gives the pass's signature, its construction rules on the
checked domain, its check, and the refinement it supports. Every
constructor checks its target contract. A check $\mathsf{check}_f(s,t,\chi)$
requires both local contracts and compares the ASTs the code compares.
Independent checking is the target; CK-Transfer and the functional-root test
in CK-EvidenceLe currently reuse producer logic, as qualified below.
Checks are sufficient structural conditions under the
premises of Section~\ref{sec:premises}: they reject some equal plans and decide
no equivalence.

\subsection{Normalization: CQ $\to$ CQ$_{\rm NF}$}
For an atom at clause $i$, walk its arguments left to right against the declared
types $\tau_j$. $B$ holds names bound by earlier clauses, $L$ names already seen in
this occurrence (reset per occurrence), $A$ bare names this atom supplies that
are not in $B$, and $Q$ is the complete logical scope (including the current
branch's binders). Literals remain in the atom and bind no name. For other
arguments, fresh $k$ starts at \code{__cq_i_j}; cases are tried in order:
\begin{mathpar}
\Rule{A-Variable}{a_j=x\quad x\notin L}
 {a_j\leadsto_{NF}x\quad[L:=L\cup\{x\}]}

\Rule{A-Repeat}{a_j=x\in L\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[k=x]]}

\Rule{A-Wildcard}{a_j=\_\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\text{unconstrained witness}]}

\Rule{A-Closed}{a_j=e\quad\fv(e)\cap Q=\emptyset\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[\mathsf{where}\ k==\mathsf{Closed}(e)]]}

\Rule{A-Prefix}{a_j=e\text{ is a remaining expression}\quad
 \fv(e)\cap Q\ne\emptyset\quad\uses(e,A)=\emptyset\quad k\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{before}:=\mathit{before}\concat[\mathsf{let}\ k:\tau_j=e]]}

\Rule{A-Local}{a_j=e\text{ is a remaining expression}\quad
 \uses(e,A)\ne\emptyset\quad k,v\text{ fresh}}
 {a_j\leadsto_{NF}k\quad[\mathit{after}:=\mathit{after}\concat[\mathsf{let}\ v:\tau_j=e,\ k=v]]}

\Rule{A-Capture}{c=\mathsf{let}\ p=e\ \lor\ c=\mathsf{if}\ e\text{ top-level, or a closed head operand/aggregate argument}\\
 \fv(e)\cap(Q\setminus\mathsf{captures})=\emptyset\quad\mathsf{binders}(p)\text{ bound nowhere else}}
 {c\leadsto_{NF}\mathsf{captures}:=\mathsf{captures}\concat[c]\text{ (dependency order)}}

\Rule{A-CaptureRef}{\mathsf{let}\ p=e\ \text{or}\ \mathsf{if}\ e\text{ in a branch}\quad
 \fv(e)\cap Q_{branch}=\emptyset\quad c\text{ fresh}}
 {\mathsf{let}\ p=e\leadsto_{NF}\mathsf{let}\ p=\mathsf{capture}\ c,\ \mathsf{if}\ e\leadsto_{NF}\mathsf{if}\ \mathsf{capture}\ c
  \quad[\mathsf{captures}:=\mathsf{captures}\concat[\mathsf{let}\ c=e]]}

\Rule{A-Alias}{\mathsf{where}\ x==y\text{ top-level}\quad x,y\text{ atom generators}\quad
 \text{no block in }q\\
 y\notin\mathsf{Protected}(q)\quad
 \text{no atom repeats a name under }[y:=x]}
 {q\leadsto_{NF}q[y:=x]\text{ without the solved identity}}

\Rule{A-Domain}{x\ op\ t\text{ (in }\code{where}\text{, an atom or negated-atom position, membership or range)}\quad
 x\text{ at a column of recorded domain id }d\text{ and payload }D:T\quad Q\vdash t:\mathsf{Closed}\quad k\text{ fresh}\\
 (op',f)=\begin{cases}(op,\mathsf{exact})&op\in\{=,\ne\}\text{ or a position}\\
 (op,\mathsf{lower})&op\in\{<,\geq\}\\
 (<,\mathsf{upper})&op={\leq}\\
 ({\geq},\mathsf{upper})&op={>}\end{cases}}
 {x\ op\ t\leadsto_{NF}x\ op'\ k\quad[\mathsf{captures}:=\mathsf{captures}\concat[\mathsf{Domain}(k,T,f,d,D,t)]]}
\end{mathpar}
A-Domain runs once per operand at normalization; a literal membership
\code{x in [t, ...]} first becomes the disjunction of $x=t_i$, \code{x in a..b}
becomes $x\geq a\land x<b$ (both \textsf{lower}) and \code{x in a..=b} becomes
$x\geq a\land x<\mathsf{upper}(b)$. Because the code map $\varphi$ of an ordered
domain is order-preserving on present values ($v\leq w\iff\varphi(v)\leq\varphi(w)$),
$x<t\iff\varphi(x)<\mathsf{lower}(t)$ (first code $\geq t$) and
$x\leq t\iff\varphi(x)<\mathsf{upper}(t)$ (first code $>t$); an absent
\textsf{exact} value is the domain's non-member code (\code{StringCode::MAX}),
which no row carries. \textsf{exact} needs \code{CodeDomain};
\textsf{lower}/\textsf{upper} need \code{OrderedCodeDomain}, so an ordered
comparison on an unordered domain is rejected by rustc. Columns without a
domain keep their operands unchanged. The captured code is then an ordinary
closed operand (A-Closed, IF-Capture); its typed domain record is carried unchanged.
Already recorded translations with the same domain id stay unchanged.
The declaration table interns domain spellings once; A-Domain compares only
those recorded ids, not Rust expressions.
Authored Rust calls, even identically spelled, never establish this provenance.
Replace the atom by $\mathit{before}\concat[R(\bar a')]\concat\mathit{after}$.
Identities are relational clauses, not guards. Row-dependent Rust guards,
lets and generators are copied; branch bodies normalize recursively with fresh names; a
row-dependent computed head becomes a final typed bind. Query-closed lets, guards,
head operands and aggregate arguments are recorded once as captures, never body
clauses, so ordering never places them; a closed branch binding keeps its binder
as a capture reference. In \code{R(x,f(x),g())}, closed
\code{g()} remains a once-bound host operand of an occurrence restriction;
the dependent \code{f(x)} bind follows the atom. No closed atom operand creates
a row binding or a Rust block dependency.
After the per-atom rewrites, A-Alias solves relational variable equalities
between top-level atom generators (in written order, keeping the left name
unless only the right one is protected). $\mathsf{Protected}(q)$ holds the
valuation (head) variables, negated atom columns, Rust binders and the
generator inputs of every Rust expression, whose spellings are observed outside
relational algebra. The solution is recorded only as plain shared names in the
NF; an unsolved equality remains a relational predicate. Later passes never
treat an equality class as a join key: lowering realizes only shared names.
\emph{Check:} the NF contract only; there is no separate correspondence check.
\emph{Refinement:} each rewrite replaces an argument by an equivalent
identity or a bind at the position Rust would evaluate it, and a pure total
closed value evaluated once equals its per-row evaluation; A-Alias substitutes
equals for equals in relational positions only, so meanings are equal.

\subsection{Ordering: CQ$_{\rm NF}\to$ VO}
\label{sec:planning-order}

\paragraph{Step-1 ordering contract.}
For a recorded scope $S=[s_0,\ldots,s_{n-1}]$, let $B_k$ be its recorded
incoming supplied bindings plus the outputs of $s_0,\ldots,s_{k-1}$, $U_k$ its
remaining steps, and $R(s),O(s)$ its declared requirements and outputs.
Visible but unsupplied free columns of a hoisted arm are not in $B_k$.
These are binding facts, not deductions from Rust syntax or types.
Write $\mathsf{ready}(s,B)$ for $R(s)\subseteq B$ and
$\mathsf{filter}(s,B)$ for $\mathsf{ready}(s,B)\land O(s)\subseteq B$.
An atom's connectivity is sharing a declared output with $B$.
``Earliest'' means before the next variable introduction: several ready
filters cannot occupy the same sequence position, so they drain as a group;
no ordering between such filters is imposed by I2.
\begin{mathpar}
\Rule{I1}{\forall k<n.\ R(s_k)\subseteq B_k}
 {S:\mathsf{Ready}}

\Rule{I2}{\forall k<n.\ O(s_k)\not\subseteq B_k
 \Rightarrow \neg\exists t\in U_k.\ \mathsf{filter}(t,B_k)}
 {S:\mathsf{EarliestFilters}}

\Rule{I3}{\forall k<n.\ s_k\text{ introducing atom}\land O(s_k)\cap B_k=\varnothing
 \Rightarrow \neg\exists t\in U_k.\ t\text{ atom}\land
 \mathsf{ready}(t,B_k)\land O(t)\cap B_k\ne\varnothing}
 {S:\mathsf{Connected}}

\Rule{I4}{C_k\text{ candidates permitted by I1--I3}\quad
 s_k\in\mathsf{allowed}(C_k,E_k,T_k)\quad
 \text{written position is the last tie-break}}
 {S:\mathsf{DeclaredChoice}}

\Rule{I5}{D\text{ optional recorded stratum demand}\quad
 W_k\subseteq D\quad
 \text{every cited reused key in }W_k\text{ matches the recorded lookup}}
 {S:\mathsf{SharedDemand}}

\Rule{VO-Order}{S:\mathsf{Ready}\quad S:\mathsf{EarliestFilters}\quad
 S:\mathsf{Connected}\quad
 \forall k.\ \mathsf{citationsExist}(E_k,T_k,W_k)\land
 s_k\in\mathsf{allowed}(C_k,E_k,T_k)}
 {\mathsf{checkOrder}(S)\Downarrow\ok}
\end{mathpar}
I4 records structural choices, or cited evidence when present; Written is
exempt from I4 only. In step 1 there is no cost stage. I5 transports optional
shared demand but does not rank candidates yet, and records no reuse claim.
The eventual I5 preference applies only within candidates tied under I1--I3.
VO-Order checks each scope independently, including nested scopes, from
recorded binding and choice facts; it neither calls the scheduler nor proves
optimality. Advice constrains introducing atoms only: ready fully-bound
checks drain independently of advised position. An authored violation of I1
or I3 is rejected with its rule identity, never repaired by reordering atoms.
A let introducing a fresh variable is not an I2 filter merely because it is
a let. A fully-bound positive atom is an I2 filter even though syntactically
it is an atom. Datalog records seed/delta identity, the driver policy and
the occurrence permutation as structural input. Step 1 retains CPU
WrittenOrder, GPU DeltaFirst and Incremental-prefix Storage selection.
Removing that permutation planner and deriving Storage from VOs is the
separately censused step 1b; no such ownership reversal is claimed here.

Let $T$ be scalar-let- and generator-supplied names and $B_w$ the written prefix. Clause $i$ provides
$\bar O_i$ and requires $R_i$:
\begin{mathpar}
\Rule{D-Atom}{c_i=A(\bar x)}
 {B_w;T\vdash c_i\triangleright(\bar x,\set(\bar x)\cap T)}

\Rule{D-Guard}{R=\uses(e,B_w)}
 {B_w;T\vdash\mathsf{if}\ e\triangleright([],R)}

\Rule{D-Bind}{\bar N=\binds(p)\quad R=\uses(e,B_w)}
 {B_w;T\vdash\mathsf{let}\ p[:\tau]=e\triangleright(\bar N,R)}

\Rule{D-For}{\bar N=\binds(p)\quad R=\uses(e,B_w)}
 {B_w;T\vdash\mathsf{for}\ p\ \mathsf{in}\ e\triangleright(\bar N,R)}

\Rule{C-Ready}{i\in U\quad R_i\subseteq B}
 {U;B\vdash i:\mathsf{ready}}
\end{mathpar}
Generators require their RHS free variables, just as scalar lets and guards
do. They are not atom occurrences or relational predicate facts. Later atoms
mentioning their outputs require those bindings rather than supplying them.
There is no written-order chain or predecessor-set condition. Generators
cannot be reduction targets, reduction supports or independent build targets;
a block containing one is not Rust-free. This remains true for a closed
expression or a generator yielding no names.
Identities and constraints require their variables and provide none
(D-Constraint). A Rust-free block provides its free/interface heading; a Rust
block requires its free names and is Rust. Heuristics repeatedly place the
least-ranked ready clause; an empty ready set is an error. Connectivity counts
only names actually shared after normalization, $s_i=|O_i\cap B|$: an unsolved
equality class (A-Alias declined) is not a realizable join key.
Let $a_i=[O_i\not\subseteq B]$. The scheduler first minimizes $a_i$,
then the structural rank below, so ready nonintroducing work precedes
introducing lets as well as introducing atoms. A final stable drainage
applies the same I2 obligation to assembled Fine and authored schedules
without changing projected subatoms or introducing choices.
\begin{mathpar}
\Rule{S-Written}{}{\mathsf{sequence}_{Written}(q)=\mathsf{drain}_{I2}([0,\ldots,m-1])}

\Rule{S-WrittenConnected}{
 C=\{i\in U\mid R_i\subseteq B\}\quad j=\arg\min_{i\in C}(a_i,i)\\
 K=\{i\in C\mid c_i\text{ is an atom},\ |O_i\cap B|>0\}}
 {\mathsf{next}_{WrittenConnected}=
 \begin{cases}

 \end{cases}}

\Rule{S-Connected}{c_i\text{ atom}\quad s_i=|O_i\cap B|}
 {\mathsf{rank}_{Connected}(i,B)=(a_i,1,[s_i=0],0,i)}

\Rule{S-Filtered}{c_i\text{ atom}\quad s_i=|O_i\cap B|}
 {\mathsf{rank}_{Filtered}(i,B)=(a_i,1,[s_i=0],f_i,i)}

\Rule{S-Greedy}{c_i\text{ atom}\quad s_i=|O_i\cap B|\\
 r\in\{GreedyWidth,Auto\}}
 {\mathsf{rank}_{r}(i,B)=(a_i,1,[s_i=0],|B\cup O_i|,i)}

\Rule{S-Elimination}{c_i\text{ atom}\quad E=\mathsf{analysis}(q).\mathit{elimination\_order}\\
 e_i=\min(\{\operatorname{pos}_E(x)\mid x\in O_i\}\cup\{|E|\})}
 {\mathsf{rank}_{Elimination}(i,B)=(a_i,1,[|O_i\cap B|=0],e_i,i)}

\Rule{O-Coarse}{\mathit{seq}\text{ chosen}}
 {\mathsf{coarse}(\mathit{seq})=[\mathsf{fullSubatom}(i)\text{ or the copied central/Rust step}\mid i\in\mathit{seq}]}

\Rule{O-Fine}{(G_0,B_0)=\mathsf{flush}(B)\quad v\text{ first eligible remaining variable}\\
 (a,G_1,B_1,J)=\mathsf{introduce}(v,B_0)}
 {\mathsf{fineStep}(v,B)=G_0\concat a\concat G_1
   \concat[\mathsf{subatom}(j,B_1)]_{j\in J}}

\Rule{O-EmptyCheck}{s_k=R@i(\bar\_)\quad
 \exists j>k.\ s_j=R@i(K)\land\mathsf{introduces}(s_j)\ne\emptyset}
 {\mathsf{omit}(s_k)}

 {\forall j>k.\ s_j=R@i(K)\Longrightarrow\mathsf{introduces}(s_j)=\emptyset}

\Rule{VO-CheckPhase}{s_k=R@i(K)\ \code{check}}
 {K\subseteq P_k\quad\mathsf{candidateProvider}(s_k)=\mathsf{false}}

\Rule{O-BlockPlacement}{b\text{ a block in ordinary ordering}}
 {b.placement={\begin{cases}\mathsf{correlated}&\mathsf{Rust}(b)\\

\Rule{O-WrittenBlocks}{t=\mathsf{WrittenCoarse}(s)}

\Rule{O-StepAdvice}{n=N(q)\quad t=\mathsf{authorSteps}(n,A)\quad
 \mathsf{erase}(t)=n\\

 {\mathsf{orderAdvice}(q,A)=t}

 {\mathsf{check}^{\mathcal{E}}(n,t)\Downarrow\ok}

\Rule{O-KnownAt}{\neg R(\bar x)\text{ at top-level clause }i\quad
 t'=t\text{ with }\neg R(\bar x)\text{ moved after the }k\text{-th positive read}\\

 {\mathsf{known}(R@i\ \mathsf{at}\ k)(t)=t''}
\end{mathpar}
A read of occurrence $i$ is \emph{keyed} under bound variables $B$
($\mathsf{keyBound}_{\mathcal{E}}(i,B)$) when every column of some recorded key
of its relation is a literal or a variable in $B$: it matches at most one row.
$\mathsf{functional}_{\mathcal{E}}(n,r)$ holds when, starting from $r$ and
closing over ready Rust bindings, every other top-level occurrence can follow as
a keyed read. With $w$ the written root (the first top-level occurrence ready
with nothing bound), $\mathsf{dom}_{\mathcal{E}}(n,r)$ holds when $r\ne w$,
$\mathsf{count}_{\mathcal{E}}(r)\ge\mathsf{count}_{\mathcal{E}}(w)$, $f_r\ge f_w$, and
no occurrence $j\notin\{r,w\}$ with $f_j\le f_w$ shares a variable with $r$: reduction
semi-joins $r$ by its filtered neighbours, so such a neighbour filters $r$ at least as strongly as $w$ by a
predicate $w$ lacks. A dominating root never trades a larger filtered input for a
smaller one under any selectivity monotone in filter rank. $\mathsf{keyedReads}$ then repeatedly expands the ready keyed
occurrence of least $(f_i,i)$ and, before it, looks up every other ready keyed
occurrence with $f_i<3$ (a non-introducing read of its bound columns). This is
RPT's LargestRoot restricted to key-functional trees: expansions never fan out,
filters reject before payload is read. Without a count for every occurrence,
with top-level blocks, or without a dominating functional root, $\mathsf{order}^{\mathcal{E}}$
is $O_{Prefix(Connected),Coarse}$ and CK-EvidenceLe reduces to CK-Order; when the
keyed order equals that order without lookups, the default plan is kept.
The current CK-EvidenceLe implementation computes functional roots by calling
the producer's ranked $\mathsf{keyedReads}$ planner for each candidate root
and testing whether it succeeds. It then checks the recorded root, keyed
first reads and filtered lookups directly; it does not require equality with
the producer's complete read schedule. Thus this root-feasibility check is
producer replay, not an independent proof of functional reachability.
Evidence chooses only: every result is a plan WF-VO and CK-Le accept on their own,
so a false count or key changes speed, never answers. O-KnownAt validates the
requested admission level and its binding prerequisites, then applies I2:
a requested late anti-join drains to its earliest ready boundary. It is
applied before Masks and re-checked afterward; no requested level exempts a
filter from VO-Order.

In $\mathsf{authorSteps}$ unadvised filters (constraints, negations,
guards) are placed as soon as ready; an unadvised Rust binding waits until the
next advised step reads one of its bindings, or the end. Pure totality makes any
position after its free variables and before its first use equivalent (WF-VO),
and this keeps advised steps adjacent, e.g. an intersection site.
For Prefix, Filtered and Elimination, ready constraints rank
$(a_i,0,0,0,i)$ and other nonatoms $(a_i,0,0,1,i)$. WrittenConnected instead
uses written clause preference for all ready work after the I2 partition,
substituting the first ready connected atom only when I3 forbids its chosen
disconnected introduction. This declared I4 policy preserves legal
introducing-binding boundaries and same-boundary filter order; it does not
eagerly hoist an introducing let just because its inputs are ready.
Auto is GreedyWidth; Elimination uses reverse maximum-cardinality search on the
primal graph, with connected-ready variables or binders first.
Written/Fine and WrittenConnected/Fine split each chosen atom in place,
then drain ready checks. $\mathsf{flush}$ emits ready waiting
steps (constraints first); a variable is eligible if no Rust step supplies it or
it is bound; $\mathsf{introduce}$ emits a subatom of its first holding atom and
then the others' checks. Every atom's full correlated row must eventually be
checked. Literal-only occurrences have an empty variable heading and
are placed as complete zero-column reads before the fine variable loop.
The production facade uses Prefix(Connected)/Coarse: the written root, then
at each step a ready atom sharing a bound name before a disconnected
one (earliest clause first), with ready relational predicates placed where
their variables are bound. Written/Coarse with O-WrittenBlocks retains
introducing-atom order and correlated blocks, but drains I2 checks and rejects
I1/I3 violations; it is not an exemption from VO-Order. Ordinary Written/Coarse
retains O-BlockPlacement and is the `plan(order(..))` fallback. Filtered/Coarse serves external planners
and R-Masks' sibling order. Under H-FilterRank, $f_i$ is
$0$ for an occurrence containing a literal or a local constant equality, $1$ for a local constant range,
$2$ for a derived domain, relational predicate or finite relational block,
and $3$ otherwise. Ordering ranks through H-Local, the same targets O-Restrict
records; the reducers and their checkers rank through the VO scope's recorded
restrictions, so a filtered rank always names a restriction the lowering
applies and a VO without restrictions (the written reference) ranks nothing as
filtered by a predicate.
Rust guards never
improve a rank, regardless of their syntax or types. This is a syntax-only priority, not a cardinality
estimate. Written remains available to explicit planner clients.

Step advice extends the occurrence selectors with \code{R@i(cols)}: the listed
query variables are the exact retained columns, including every already-bound
column of that occurrence. A bare \code{R@i} reads the full correlated row.
Partial reads introducing a variable are Fine steps (at most one new variable);
adjacent reads of different occurrences on that variable expose intersection
points, without choosing a Physical implementation. A non-introducing explicit
partial read before any Fine read of that occurrence selects it into $L$, the checked
lookup/expand set. Each selected occurrence must then have exactly one later
full expansion with written ownership. An unbound listed variable denotes
a Fine introduction, not an unchecked lookup. Duplicate/foreign columns,
reads after expansion, incomplete rows and unsatisfied dependencies reject.
Ready nonatoms are placed by free-variable readiness, constraints first;
unnamed occurrences follow in written priority, while named partial occurrences
must be completed explicitly. Without step advice, ordinary coarse advice
and the default planner remain unchanged.
\[
\Rule{H-Local}{P\text{ a top-level }\mathsf{where}\text{ predicate or literal equality at clause }k,
 \text{ or an E-Domain }D_x\text{ of one}\\
 \vars(P)\ne\emptyset\quad\vars(P)\cap\mathsf{RustBound}=\emptyset}
 {\mathsf{targets}(P)=\{i\mid c_i=R(\bar x)\text{ positive},\ \vars(P)\subseteq\bar x\}}
\]
H-Local is independent of where $P$ is written: an atom written after $P$
is a target exactly like one written before it. A hoisted block that takes a
finite prefix domain imposes no positional premise either: its domain is the
VO prefix that binds its free columns (WF-BlockPlacement), which already
carries every restriction of that prefix and still contains the free values of
every answer.

 \{P\mid\mathsf{restrict}\ R@i\ \mathsf{where}\ P\in t\}\ \text{(reducers)}\quad
 L_i=\{0\mid O_i\text{ has a literal argument}\}}
 {f_i=\min(\{3\}\cup L_i\cup\{\mathsf{strength}(p)\mid p\in P_i\})}
\]

\[
\Rule{CK-Order}{\mathsf{WF}_{NF}(s)\quad\mathsf{WF}_{VO}(t)\quad t.cq=s\\
 \mathsf{OrderObligations}(s,t,\chi)}

\Rule{CK-OrderObligations}{\forall\sigma\in\mathsf{scopes}(t).\ \forall k<|\sigma|.\ \sigma_k\notin\mathsf{Reduce}\\

  \mathsf{intro}(\sigma_k)\ne\emptyset\ne\mathsf{intro}(\sigma_l)\Rightarrow\mathsf{clause}(\sigma_k)\le\mathsf{clause}(\sigma_l)\\
 \mathsf{restrictionsConsistent}(s,t)}
 {\mathsf{OrderObligations}(s,t,\chi)}

\Rule{CK-Restrict}{\forall P\text{ written}.\ |\{\mathsf{where}\ P\in t\}|\in\{0,|\{k\mid c_k=P\}|\}}
 {\mathsf{restrictionsConsistent}(s,t)}
\]
O-Restrict records where every relational predicate runs. Each H-Local target
becomes a restriction \code{restrict R@i where P;} at the head of its scope,
in H-Local order; implied domains exist only as restrictions. A written
predicate keeps its prefix \code{where} step unless every written instance of
it has a target. Every ordering producer (plain, advised, evidence, LE and the
planners' transfer route) records restrictions this way; a rescheduling
producer (LE, advised lookups) restricts its own schedule, so prefix
predicates still constrain its choices. The written
reference (\code{compile_written}) records none, but still obeys VO-Order.
In CK-OrderObligations, $\mathsf{scopes}(t)$ is the top-level step list and every
block arm's step list, $\mathsf{clause}(\sigma_k)$ the NF clause of an atom or
block step, $\mathsf{cols}(\sigma_k)$ its listed bound columns,

GYO starts at $Z(i)=\widehat X_i$, applies the least private pair, else the least

\begin{theorem}[GYO]
GYO terminates and accepts exactly the occurrence hypergraphs with a join tree;
its parent map has running intersection on the original edges.
\end{theorem}
\begin{proof}$|\dom Z|+\sum_i|Z(i)|$ decreases. A variable in two active edges is
never private, so an absorption's shared variables lie in its container: an ear
removal. Both steps preserve join-tree existence, and a join-tree leaf is always
removable, so an acyclic input ends in one empty edge; reversing absorptions
rebuilds the tree.\end{proof}

\begin{theorem}[Full reducer]
On a join tree, upward reverse-BFS then downward BFS semijoins preserve
$Q=\bowtie_iL_i$ and leave each $L_i=\pi_{X_i}Q$, in $2(n-1)$ steps.

join; the root is fully supported; downward, a surviving child tuple matches a
supported parent tuple and the two witnesses combine. Every full witness
survives every semijoin.\end{proof}

the join, so meanings are equal; Rust steps are untouched.

In CT-FullWitness, $v_f\preceq v$ means recorded restricted-view ancestry,
not equality of occurrence numbers. The lineage $n\leadsto_K q$ must retain
every binding in $K$ with its original column origin at every node. It may
follow selections, projections that retain all of $K$, the left operand of
a semijoin, or either operand of a natural join. It never crosses Rust,
antijoin, union or grouping. A full row on an unrelated branch, an ancestor
instead of a descendant restricted view, or a dropped and later rebound key
does not discharge the obligation. Branch extraction remaps the requesting
node together with its occurrence and both restricted views.

\emph{Local equivalence argument.} The final join matches every participating
binding with the complete row $f$. Since $f$ descends from both restricted
views, it can supply both earlier existential projected witnesses with those
same values. The binding-preserving lineage does not forget a match or
introduce an opaque observation between the request and this join. Thus
using that one complete row establishes the original correlation; the
reverse implication is immediate from the already-present full read.
This discharges only that request. Every other projected-view obligation,
fixed occurrence, equality, predicate, reduction edge, Rust payload and output
binding remains checked. It is not an occurrence-only witness unification.

downstream join keys. The ordinary structural comparison then checks the
resulting equivalent witness against the supplied VO schedule. Required
named reductions are still checked on the \emph{original target}; inverse
expansion cannot invent their edges or column matches. This certificate
does not recompile the VO, select a planner, or merge equality facts from
independent existential supports. An unresolved split projected-witness view
in either original schedule excludes this fallback: an inverse expansion
cannot invent the actual full-row certificate required by CT-FullWitness.
Rust, negative and block programs retain their existing checker.

\paragraph{Example: free variables determine eligibility.}
In \code{answer(a,w) :- R(a,x), S(a,y), T(y,z), let k = combine(*x,*y), let
p = left_key(k,*y), let q = right_key(*x,*z), U(p,q,w), where x > 0, if
permitted(k,*z), V(w);} the relational predicate may select $R$ early.
\code{combine} requires only $x,y$, not $T$; \code{permitted} requires $k,z$,
not the preceding independent binding of $q$. Both Rust expressions remain
unchanged. A Rust spelling \code{if *x > 0} would not produce a range read.

retention justifies projection before a join:
\begin{mathpar}
\Rule{O-Leaf}{i\in O}{i:\{i\}}

 {(T_1\bowtie T_2):C\cup E}

\subsection{Physical lowering: IX $\to$ Physical}
Lowering restates each RA result with one physical operator and the mode its

\subsection{Structure selection: Physical $\to$ Structures}

\subsubsection{Representation recording: Structures $\to$ Structures}

$s.repr$, $s.stages$ and $s.retained$ denote the corresponding checked-analysis

field. A result in a definition-order list denotes that definition's name.
For \code{cq_represent}, let $E_s$ be the results admitted by its direct-chain
eligibility function: noncanonical pipes whose operator is rename, select,
point, range, project, semi or anti, whose predecessor is eligible, and whose

columns. A rename has no predecessor; semi and anti use their left input.
Write $p_s$ for this predecessor function and $p_s^*(X)$ for its reflexive
ancestor closure. Let $L_s(r)$ be the first recorded scan lineage and

\[

\subsubsection{Stage recording: Structures $\to$ Structures}
For \code{cq_staging}, $s+e$ appends one entry without changing any other field.

\paragraph{Push realization.}
The push printer consumes the same checked Structures decisions and shared
source preparation. Preparation exposes the fused positional pipe before any
later iterator adapter consumes its compiler tokens. Push loops over those
accepted IDs, fetches each surviving host row, and invokes its sink directly.
All residual predicates remain inside the prepared ID stream. A retained let
constructs its named Selection once; repeated scans use that snapshot's rows,
and payload indices and AdaptiveKeySets use the recorded Build projections.
There is no intermediate traversal Vec beside a Selection. Key-only membership
(including anti and computed-left reads) uses the recorded ownership layout;
negative membership does not use positive interval rejection. Standalone union
arms keep their scopes, and fused dependent branches consume their prepared
stream once. Lazy membership retains its existing empty-left nonforcing rule.
\begin{mathpar}
\Rule{IF-PushPositional}{r\text{ has checked ID stream }I\text{ over base }H}
 {\mathsf{push}(r,k)\longmapsto
  \code{for id in I \{ k(row\_at(H,id)); \}}}
\end{mathpar}
The user advises \code{select(positional(H,...))}; the selection pass decides
and records the representation. Without advice the existing representation is
retained. Both printers enforce the Structures contract and emitted
\code{PositionalRows}/\code{BlockRead} guards. Neither infers positional
capabilities from a Rust host type. Push continues to reject written merge and
smallest choices, including unused results.

Native keyed reads come from host declarations and are recorded in Structures,
with a recorded fallback otherwise. Merge readers record an ordered fallback,
not a native ordered read, for compatibility with Sequence keyed lookups.
Unrecorded const/range reads scan and
filter without building; merge requires \code{OrderedRead}. Rows borrow
host and built fields; computed columns and lookup keys are owned; canonicality
never follows from a host type.

\paragraph{Opaque generator realization.}
Write $I_r$ for the input row stream and $\mathsf{extend}_p(\rho,v)$ for
destructuring item $v$ and extending the row with the fresh pattern columns.
The same checked Bind node has the following two realizations:
\begin{mathpar}
\Rule{P-For}{\mathsf{Bind}(r,p,e)\text{ carries the \code{for} token}\\
 \mathsf{scopeOK}\quad\mathsf{unchangedExpression}\quad\mathsf{finitePureTotal}(e)}
 {\mathsf{pull}:

\end{mathpar}
Both evaluate the RHS in the input environment, exactly at the opaque step;
iteration stays inside that step's row scope. Generated item columns have
the same owned-computed representation as scalar bind columns, while existing
host references retain their origins. No collector, sorting or deduplication
is inserted at the generator itself; existing canonical boundaries suffice.
Shared generator callables retain host-column lifetimes for iterators borrowing
their inputs, but quantify computed-column borrows independently for every
call. A row-local computed value must not borrow for the enclosing callable's
lifetime merely because the unchanged expression also captures host state.
Zero-sized type witnesses connect prepared scalar results and generator item
patterns to later callable inputs. Rust infers unannotated computed columns
from these connections; preparing a witness evaluates neither the original
expression nor its pattern-extractor closure.
Absent the token, the scalar printer remains a one-row extension and must not
call \code{IntoIterator}. Generator iteration is pure and total by premise;
stage eligibility depends on its representation. Rust checks iterator/item
and lifetime obligations; the checker preserves the tag, original expression
and free-variable bindings; finite pure total iteration remains a host premise.

\subsection{Shared planning compositions}
With $N$ normalization, $O_{h,s}$ ordering, $R_{g,r}$ reduction, $E$ elaboration,

Automatic Plan-Le keeps the written outer stream and written column
ownership. An advised schedule chooses its root: its outer stream is its
first read, which is expanded once, and WF-VO alone fixes which columns each
expansion introduces; lookups still introduce nothing. A zero-column lookup
of an occurrence later introducing columns is omitted (O-EmptyCheck); the
expansion itself establishes nonemptiness. Other residual root checks are
guards over Unit, never unit-projected enumerations. Final I2 drainage
preserves a check moved across an introduction using the recorded \code{check}
marker, including its original occurrence and key. Existing markers survive
further drainage. Stationary Written/Fine reads and LE lookups are not globally
reclassified: their previously admissible introducing/intersection choices
remain available. RA and Physical transport the fact and independently check
heading preservation; new adjacency cannot create a new provider phase.
The relational correspondence proof may eliminate redundant checks or coalesce
identical occurrence/key reads. Surviving demanded phases must retain their
markers; moving a marker to another key is not elimination. Extra restrictive
markers are lawful. A zero-heading projection of an occurrence is still a
read, not proof that a root guard disappeared.
Demand-driven expansion obeys I3 even when an unrelated aggregate guard
demands a disconnected occurrence first.

The \code{no_reduce} option disables implicit Masks reductions, not explicit
\code{reduce(T with S)} advice. Such advice therefore composes with the empty
Masks schedule. A \code{skip(T with S)} still requires an existing Masks
reduction; under \code{no_reduce} it fails the R-Advice premise rather than
silently becoming a no-op.

\code{order(transfer)} is an exact-semijoin adaptation of robust predicate
transfer (Zhao et al., SIGMOD'25), not the paper's vectorized Bloom pipeline or
RPT+'s adaptive execution. Transfer uses the shared CQ scheduler's declared
WrittenConnected I4 preference (S-WrittenConnected): preserve legal written
introductions, including introducing-binding boundaries and same-boundary
filter order, with readiness, I2 drainage and I3 connectivity enforced first.
It has no separate boundary-limited atom scheduler and constructs no illegal
Written intermediate. Genuinely disconnected components are permitted only
when no connected atom is ready.
The reduction tree is rooted at the stream;
when that is the largest relation the root coincides with LargestRoot.
The most-shared-first spanning core matches the paper's maximum-spanning-tree weights.
The forward pass is the Masks pass plus the stream's reductions by its filtered
children; the backward pass then reduces each child atom by its already reduced
parent. As in RPT, no transfer starts from a side without filters, transfers
follow only edges whose clauses share a variable (a join predicate), and blocks
are never transfer supports beyond the Masks atom-to-block cuts. Transfers are
exact semijoins, not Bloom filters. Checked absorption removes redundant support
versions before Physical chooses which remaining results to retain. Scopes containing
opaque Rust keep only their Masks reductions: there the structural RA
correspondence check rejects some sound transfer schedules.
CK-Transfer currently erases the recorded reductions, checks the remaining
ordering, reruns Masks construction and the transfer producer, and requires
exact equality with the target. The rule above describes that implementation;
it is not an independent check of the transfer premises.

\code{order(le)} is the Lookup \& Expand decomposition of Birler, Kemper and
Neumann (VLDB'24) as a VO construction: a lookup is a partial subatom that
introduces no names (a semijoin of the stream prefix), an expansion is the
later full subatom of the same occurrence. Lookups are placed in GYO ear order
as soon as their bound key is available, expansions as late as column demand
or scope exit permits, so acyclic scopes form two-phase plans.
Expansions are coarse full rows under an explicit CK-Le obligation, not Fine
subatoms. Whether a later probe reuses the lookup's cursor is a Structures
representation decision, not part of this plan.
The phase checker is shared by \code{cq_order} and the external planner, rather
than reimplemented by the facade. For Plan-Le, $L$ is every inner occurrence
in each scope, the outer has one full read with written ownership, and the
caller additionally checks Masks reductions. For step advice, $L$ is only the
explicit lookup occurrences at the top level; unselected Fine/coarse reads and
unchanged nested scopes retain WF-VO obligations, and the advised outer stream
is the schedule's first read (not necessarily the written one). The phase check
runs before Masks and before optional reduction advice; checked expansion
simplification follows elaboration.

\code{plan} is left-deep in Prefix(Connected)/Coarse order by default, with
explicit or evidence-based order available, and defaults to checked Masks
reduction: every scope, acyclic or cyclic, reduces its inner clauses along the
outer-rooted reduction tree (R-Masks) and by exact atom-to-block cuts; every
branch is its own scope. Reduction compilation is independently checked before
elaboration, and elaboration is checked against the reduced VO schedule. The
external Hypergraph and Transfer planners additionally apply a checked RA
realization rewrite. It uses
$L\ltimes(R\ltimes L)=L\ltimes R$ and
$L'\bowtie(R\ltimes L)=L'\bowtie R$ only when the required shared columns of $L'$
are proven contained in $L$ by reduction lineage. The corresponding left-operand
law removes $(L\ltimes R)\bowtie R$'s duplicate membership test (and similarly
for a semijoin consumer). Right-side support pruning takes precedence; the
left-side law must be proved using the surviving RHS, not a discarded
restriction. This is local absorption, not a maximal fixed-point guarantee.
Dead reduced copies are removed; independent consumers that still need a
reduction keep the same restricted witness alive.
The rewrite is checked against the original RA and does not alter the reduction
algorithm.

Here \code{check after [i,...]} records the introducing occurrences crossed
by the producer's I2 move, hence present in its former positive prefix.
Lowering transports it. $\leadsto_K$ follows the sole
consumer's left input, retaining every already-bound key in $K$. It stops
at Rust, negation, a branch, projection loss, another introduction, or the
returned result. The restoring join must read the exact named support,
not merely a descendant with the same occurrence. The restricted result
must become dead. Ordinary local absorption completes first, so a declined
proposal cannot undo an existing local realization. The producer records
\code{absorbed r via m}; the independent certificate checks the transported
former occurrence, exact support, local intermediate RHS and restoring join.
This is only preservation of a moved check's pre-I2 input, not the general
future-support reducer law. Unmoved plans cannot acquire this absorption.
For a moved check separating $(P\ltimes L)$ from its former join with $L$
or with the reciprocal reduction $L\ltimes(P\ltimes L)$, the same recorded
restoring join may certify \code{absorbed left r via m}. The certificate
requires that exact support or exact source reciprocal pair and preserved
keys, not arbitrary descendant support. Ordinary absorption and liveness resolve
together, so the moved check cannot keep either redundant reduction alive.

For LE's checked RA \code{cq_ra_rewrites::simplify_expansions} pass, let $H_L,H_R$ be the
source operand headings, $K=H_L\cap H_R$, and $D_s(r)$ the demanded columns of source result
$r$. Under set canonicalization the additional local laws are
\[
 \pi_D(L\bowtie R)=\pi_D(L\ltimes R)\quad(D\subseteq H_L),
 \qquad L\ltimes R=L\quad
   \bigl(\pi_K L\subseteq\pi_K R\bigr).
\]
Thus a named expansion $r=L\bowtie R$ may become $L\ltimes R$ only when
$D_s(r)\subseteq H_L$; with the same demand premise it may be bypassed when
the support is already witnessed. A redundant semijoin may likewise be
bypassed. These laws concern canonical results, not bag multiplicities or
opaque Rust invocation counts.

The certificate independently propagates demand backwards through the
\emph{source} DAG: seed the output heading, retain projection attributes and
selection variables, and require every natural-join and semijoin shared key
even if its column is absent from the final output. Propagate these demands
to each operand on its source heading. Merely checking that the target is
well headed is insufficient: dropping a column can silently remove a later
implicit join equality. Support containment requires the \emph{same named
result} $R$ in $L$'s positive lineage, with every column of $K$ retained at
each step. Lineage may follow projection, selection, either natural-join
operand, or either semijoin operand: a semijoin guarantees an existential
right witness, but only on keys retained along the complete path.

The certificate replays these local laws, recomputing source demand after
each proved step, and finally requires the exact proposed target. It
substitutes proved aliases in every surviving operand and output and permits
removal only of unreachable pure definitions. The new laws conservatively
decline programs containing binds, guards, anti or union; opaque execution,
negative originals and block ancestry are therefore unchanged. The general
schedule contract is not weakened.

\paragraph{Join-filter selection and realization.}
\textsc{SEL-JoinFilter} records a scalar filter for every admissible
(\textsc{STR-JoinFilter}) covering probe or semijoin into a statically filtered,
total single-level build, one per scalar column of its key, at the scan its
exclusive spine reaches. A scan may carry filters from several builds.
Every eligible payload-index build whose selected token declares
\code{join\_filter} defaults to \code{join\_filter\_membership}, spelling
\code{DenseMembership<K,67108864>}, with conditional projected-key construction.
Explicit borrowed advice requires source \code{run\_filter} and the scalar
complete stored key layout; its token declares \code{borrowed\_filter}.
Explicit attached advice declares \code{attached\_filter}; these realization
facts are mutually exclusive and neither is selected by source retyping.
A membership-only build already answers
the same exact key test and receives no redundant supplementary filter.
The dense provider requires \code{K: OrderKey} (\textsc{STR-AdaptiveMembership});
a key without it is a rustc error at the one typed build, never a hash
fallback. Explicit \code{retype} advice records another filter provider.
Selection does not sample cardinalities or assume keys or foreign keys.
Approximate structures live in an external feature and require explicit
\code{cq_rewrites::retype} advice; the printer has no algorithm-specific branch.
Every recorded covering witness is validated before runtime filters are shared.
Sharing requires the same scan occurrence, build version, scalar key, source-index
layout, filter type and column marker; covering-operator identity alone does not
require another filter. First-witness order supplies scan-local identities, also
used to distinguish profile labels.
\textsc{IF-JoinFilter} consumes recorded source and realization facts.
With neither realization fact, \code{Build} consumes projected
\code{Keys::distinct\_keys} only after activation. Exact source finalization uses
a unit sidecar only for an authored optional-statistic guard. Default filters
retain ordinary construction and \code{Keys::key\_count} activation. Explicit borrowed \code{RunFilterView} references completed ordered keys.
Explicit \code{attached\_filter} uses a \code{BuildSidecar} incremental builder
through \code{BuildWithSidecar::build_with_sidecar::<ROWS,MAX\_GROUP>(source,builder)}.
That result publishes index and filter together; recursive tuple builders
attach multiple filters without a post-build \code{distinct\_keys} scan.
The Structures \textsc{STR-Construction} record supplies the row/max mask.
Its checker verifies provider-declared \code{statistics\_build} support and
matching immutable publication witnesses, without replaying selection.
Ordinary records emit \code{Build::build}; demanded records emit
\code{BuildWithStatistics}. Printers never select a protocol from accessor
declarations. Unrequested accumulated scalars are absent; cheap lengths remain.
Rust proves the marker's \code{ColumnSlot} and the constructed filter's
\code{require::conservative::<K,T>} obligations. Borrowed views instead implement
\code{ReadPredicate}, with optional \code{RunFilterPredicate} preserving identity;
they do not implement \code{ConservativeMembership}. Realization then
filters positions before fetching payloads: the first filter through the
block-skipping read, the others on its surviving positions, in decision order.
Host block bounds use the provider's conservative \code{any_in}; an absent bound
never skips a block. Each covering exact operator is unchanged, so conservative false
positives only perform extra probes. No opaque guard or bind is crossed.
A scan read before some covering provider is built (for example a retained
host publication ordered ahead of that build) applies only the filters already
built: an omitted filter is the trivial conservative filter that passes every
key, so the covering exact operators still decide membership.
\textsc{SEL-FilterPolicy} records every filter's one policy from final
positional bases: \code{policy abandon 35 of }$B$\code{ keys }$S$ when its
build has a positional lineage base $B$, otherwise \code{policy always}. The key
source $S$ is \code{key\_count} (\code{Keys::key\_count}, constant cost, which
completes a deferred build), or the covering provider's declared exact Keys
statistic accessor when authored advice selected a borrowed or attached
realization. This measured incumbent is the only automatic policy. The P7.3 cost
rule may only veto it from recorded evidence, and no recorded evidence supports
a veto: unknown evidence keeps the incumbent. \textsc{STR-FilterPolicy} checks
the base, percentage and statistic declaration without rerunning selection.
\textsc{IF-JoinFilterAbandon} carries out the recorded policy at runtime. A recorded
accessor returns \code{Option<u64>}, and absence selects identity rather than a
\code{Keys::key\_count} recount; \code{key\_count} is exact. Present build keys are
compared with the recorded population using \code{u128} products of \code{u64}
counts. An abandoned filter passes every key and skips default projected
construction. Explicit attached construction observes keys before activation,
and abandonment does not promise to recover that construction cost.
The printer derives no policy; only exact covering operators decide membership.
