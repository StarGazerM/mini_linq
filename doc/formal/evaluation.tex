\section{Conformance and validation}
\label{sec:evaluation}
The implemented chain is \code{CQ -> RA -> IX -> Physical -> Structures -> Rust}.
Its CQ-to-RA arrow contains CQ-NF and VO nanopasses. The structural passes have
separate correspondence checks described in Section~\ref{sec:pass-contracts};
realization has no \code{check}. The languages have parser round-trip and
contract tests in \code{cq-lang-*}. The evidence below is
what the repository exercises; it is not a proof of the runtime trait laws for
arbitrary user types.

\begin{center}\small
\begin{tabular}{p{.29\linewidth}p{.61\linewidth}}
\toprule
Obligation & Current evidence\\
\midrule
IX & Named $D$, exact versions, canonical column ordinals, reused demands,
complete demand coverage and first-use numbering
(\path{passes/cq-index-policy/tests/index_demands.rs}).\\
Physical & One operator per result, operand-derived probe/semi demand checks,
modes checked by use, \code{canon} on the return when uniqueness is not inferred
(\path{passes/cq-physical-lowering/tests/lowering.rs}).\\
Structures & Every keyed read answered by a host key fact or a built type,
merge sides ordered, canonical return
(\path{passes/cq-structure-selection/tests/selection.rs}).\\
Printed program & Borrowed host/built fields and head-order output, owned
host-key cloning, generated trait guards and authored syntax fixtures
(\path{passes/cq-physical-realization/tests/realization.rs}).\\
Storage laws & Abstraction functions of \code{HashIndex}, membership and
ordered cursors against an independent bag oracle
(\path{runtime/cq-storage/tests/}).\\
Whole chain & Host maps probed in place, compiler-built indexes, a
user-defined \texttt{\#[index(Type)]}, merge joins over built ordered maps,
Yannakakis semijoin passes as membership tests, bounded ordered scans and a
computed head column, each compared with an independent oracle
(\path{facade/mini-linq/tests/physical_query.rs}); the runnable
\path{examples/composition/} binds the post-RA slots it uses, with a policy wrapper.\\
\bottomrule
\end{tabular}
\end{center}

Logical YA reduction tests are retained in \code{cq-reduce}, the
relational oracle and case corpus in \path{test-support/relational/}.
Negation and aggregation syntax parse but fail the CQ contract. Recursion,
incremental evaluation and general physical cost search are unsupported.
Generic/Fine planning and optional binary intersections exist; no WCOJ
complexity guarantee is established.
No performance or asymptotic claim follows from fixture agreement.
