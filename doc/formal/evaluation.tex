\section{Conformance and validation}
\label{sec:evaluation}
The implemented chain is \code{CQ -> RA -> IX -> Physical -> Structures -> Rust}.
Each pass has a \code{check} over its source and target, and the languages have
parser round-trip and contract tests in \code{cq-ir}. The evidence below is
what the repository exercises; it is not a proof of the runtime trait laws for
arbitrary user types.

\begin{center}\small
\begin{tabular}{p{.29\linewidth}p{.61\linewidth}}
\toprule
Obligation & Current evidence\\
\midrule
IX & Named $D,U$, exact versions, canonical column ordinals, reused demands,
missing and incorrect use-reference rejection
(\path{crates/cq-index-policy/tests/index_demands.rs}).\\
Physical & One operator per result, modes checked by use, \code{canon} on the
return when uniqueness is not inferred
(\path{crates/cq-physical-lowering/tests/lowering.rs}).\\
Structures & Every keyed read answered by a host key fact or a built type,
merge sides ordered, canonical return
(\path{crates/cq-structure-selection/tests/selection.rs}).\\
Printed program & Structures printed in head order without binding copies
(\path{crates/cq-physical-realization/tests/realization.rs}).\\
Storage laws & Abstraction functions of \code{HashIndex}, membership and
ordered cursors against an independent bag oracle
(\path{crates/cq-storage/tests/}).\\
Whole chain & Host maps probed in place, compiler-built indexes, a
user-defined \texttt{\#[index(Type)]}, merge joins over built ordered maps,
Yannakakis semijoin passes as membership tests, bounded ordered scans and a
computed head column, each compared with an independent oracle
(\path{crates/mini-linq/tests/physical_query.rs}); the runnable
\path{examples/composition/} binds every macro slot.\\
\bottomrule
\end{tabular}
\end{center}

Logical YA proof and relational-oracle tests are retained in
\code{cq-query-lowering}. Recursion, aggregation, negation, incremental
evaluation, general physical cost search and WCOJ remain outside the language.
No performance or asymptotic claim follows from fixture agreement.
