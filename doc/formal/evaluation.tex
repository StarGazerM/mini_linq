\section{Conformance and validation}
\label{sec:evaluation}
The current admitted exact-index domain has an implemented IX analysis,
structural Physical selection, generic callback driver, and external borrowed
providers. The whole-query hash/configured/Native routes have been removed.
This is not feature parity with those retired prototypes.

The complete three-input fixture uses a slice, hash map and B-tree map in one
query. A separate full-CQ fixture includes terminal projection and compares
answers over 256 input subsets. Its trace is kept separate from the direct-RA
fixture. Its independently authored IX, Physical assignment table and completed
Rust[Access] are compared with actual procedural-macro outputs. External
callbacks are captured in the same compiler-process invocation order. The
capture returns original token streams; it does not reconstruct the compiler
or flatten away its boundaries. Source hashes and an instrumentation patch
record the observed source. See \path{doc/ix-physical/realization-trace/}.
A separate full-CQ pull capture in \path{doc/ix-physical/pull-trace/} also checks
the named Pipeline boundary before Rust adapters appear. It observes zero source
evaluations at construction and unpolled drop, one row per source at first
success, and resumption within the existing innermost bucket.

The normal workspace test command excludes opt-in unfinished HW4 teaching
exercises. The 19 September run passes 312 tests; three trace-dependent tests
also pass separately against fresh captures. The feature matrix passes all 24
configurations, 12 isolated frontend probes pass, and workspace clippy passes
with warnings denied. These checks describe the active workspace,
not the removed physical tests or every proposed extension. Logical YA proof
and relational-oracle tests were retained in \code{cq-query-lowering}.
Storage and Access/Pipeline tests establish only their own component properties.

The authored local two-output and auxiliary-index fixtures in the paper remain
expectations; the executable complete-module fixture is separate. General
stored intermediates, composite/empty index providers, additional physical RA
rules, block/YA realization and trie WCOJ remain unimplemented. Provider laws
are conditional obligations, not theorems checked for arbitrary external Rust.
No performance or asymptotic claim follows from fixture agreement.
