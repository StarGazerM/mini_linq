\section{Implementation evidence}
\label{sec:evaluation}
The artifact checks planning structure, relational answers and compiled
execution separately. Its main experiments are:

The CQ oracle enumerates valuations and checks whole atom tuples. A separate
RA interpreter uses nested-loop joins and set projection. Authored RA plans
are compiled independently, so a physical-lowering failure can be separated
from an incorrect planner output. Neither expected plan is generated by the
planner under test. Public comparisons normalize order while retaining
duplicates, and include signed data, reversed duplicate inputs, each input
emptied separately, and repeated queries.

Twenty shape bodies are alpha-acyclic; triangle, four-cycle, spade, barbell
and four-variable Loomis--Whitney exercise cyclic fallback. Other cases
distinguish occurrence self-joins, composite keys, no-new-column joins,
disconnected products, existential components, bushy assembly and projection.
The claw separates cyclic SIP adjacency from an acyclic hypergraph.
A ternary relation tests whole-tuple constraints that pairwise projections
would lose. For each YA-frozen occurrence, the oracle checks equality with
the projection of the full join, detecting incomplete reduction even when
final answers happen to agree.

Mutation tests remove steps, drop keys or predicates, reuse stale semijoin
versions, prune prematurely and forge reported arities. Contracts must reject
these independently of answer equality. Exact built-in policy coverage is
narrower: the legality checker deliberately accepts alternative legal schedules,
so separate trace assertions are needed to test a heuristic's tie breaks.

The expression fixtures cover literals, destructuring, calls/macros,
repeats/wildcards, computed arguments, guards and heads. Empty-binding tests
require successful typed lowering and correct callback populations; direct
Access tests reject rebinding and unavailable visible RHS names.
Counterexample~\ref{cx:effects} instead requires the two backends to differ.
In the authored expression example, a dependent guard's placement is checked
by intermediate counts; this database's final answer alone would not expose
its omission.

The typed harness invokes unoptimized rustc even under Cargo release;
public release tests exercise optimized generated code. The artifact README
records commands. The manifest links 140 main-manuscript rules and 14 implemented
Access-refinement rules to source locations, including the 14 planner commands.
The physical rule map additionally links its rules to algorithms/model functions.
\code{check.py} checks coverage and drift, not semantics. The pass gates share
dependency analysis; bounded experiments do not discharge Section~\ref{sec:scope}'s
obligations or establish performance bounds.
