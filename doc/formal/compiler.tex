\begin{abstract}
MiniLinq compiles conjunctive queries through named relational algebra and IX,
which records required index demands over exact RA results.
A caller-supplied, query-independent policy then fixes one physical
operator per result (Physical) and binds every keyed read to a host key fact or
a built Rust structure (Structures). Physical derives demand uses from its
operands; a printer emits one pull program over the
runtime operation traits. We specify CQ, CQ-NF, VO, RA and IX with syntax,
semantics and algorithmic rules, and give local contract rules for Physical and
Structures. Separate pass correspondence judgments state the implemented checks;
realization is supported by oracle tests, rustc trait guards and expansion fixtures.
\end{abstract}
