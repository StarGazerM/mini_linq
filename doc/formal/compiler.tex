\begin{abstract}
MiniLinq compiles conjunctive queries with native Rust expressions through
independently usable relational, index, access and iterator languages.
We specify each boundary by administrative rules and give explicit algorithms
for GYO recognition, Yannakakis reduction and dependency-constrained planning.
A worked query follows composite keys, filter pushdown and column pruning
through every IR. Computed arguments and let clauses expose additional
directional requirements; an authored lower plan demonstrates a legal
optimization beyond the current planner's search.
The specification relates these algorithms to the Rust implementation and
states the contracts needed to replace a pass or quote a lower language.
Preservation arguments assume an admissible relational host; a compiled
effect counterexample rules out unrestricted equivalence of lazy and
materialized execution. Independent valuation and graph oracles, mutation
checks and compiled tests provide bounded implementation evidence.
\end{abstract}
