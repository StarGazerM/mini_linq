Compiler audit snapshot — 17 September 2026

Scope and baseline
Commit f44744e saves the staged borrowed implementation before the naming change.
The current revision renames six compiler crates, implementation modules,
procedural macros, features and administrative configuration together. Callers,
teaching extraction, tooling and the manuscript use the current names; no old
API aliases are retained. doc/NAME-AUDIT.md inventories all 44 exported macros.

The compiler boundaries remain:
CQ -> RA -> IndexRequirements -> Rust[Access, Native] -> Rust[Pipeline, Native] -> Rust.
Rust[...] denotes ordinary Rust containing macro invocations, not a new IR.
Configured relation lowering accepts RA directly; Access set-loop lowering emits
Rust directly. These existing differences are explicit, not hidden by naming.
The rename does not add a stage, planning feedback or a runtime interpreter.
IR, runtime storage and workload implementation files are unchanged from f44744e.

Borrowed lowering consumes IX with empty demands, rejects Select, Extend and
computed outputs, and emits checked local Access regions. Support, existence
and final answers select separate Pipeline endpoints. Shared/restarted results
use Native Build/Scan and the BuildReplay/ReplayRead storage traits. Payloads
remain borrowed. Construction performs no input scan or field read; existence
stops at its first witness. Replay can retain full inputs, comparisons remain
nested, and replay uses non-Send Rc state. These are finite stable pure-value
contracts, not effect or performance claims.
