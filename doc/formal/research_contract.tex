\section{Pass contracts and acceptance}
\label{sec:research-contract}
Each language has syntax, a well-formedness judgment and a meaning independent
of the pass producing it. For a selected implementation $f$, require
\[
 \mathsf{WF}_L(s)\land\mathsf{Domain}_f(s,\chi)
 \quad\Longrightarrow\quad
 f(s,\chi)=t\ \land\ \mathsf{WF}_M(t)
 \ \land\ \sem s_L\sqsubseteq\alpha(\sem t_M).
\]
$\chi$ is explicit configuration and $\alpha$ relates the target observation
to the source meaning. An unmet domain premise must be diagnosed. A pass must
follow the stated boundary: physical lowering derives operands from RA and
checks their demands in IX; it cannot invent a missing demand or substitute
a different RA version.

\paragraph{Recorded physical decisions.}
The caller selects public lowering, rewrite, selection and printer paths with
pass-local arguments. Physical records operators, modes and canonical
boundaries; Structures records concrete built, host-fallback, retained-row and
dedup types. Arguments are not carried into later programs as configuration.
Declaration order fixes host layout. Stable autoref dispatch chooses native
reads when supported, with recorded lazy per-query fallbacks. Host types never
establish plan canonicality. The default selection constructor preserves Physical decisions; its
correspondence check also admits an explicit Physical rewrite. The printer
consumes the checked recorded decisions.
Rust checks the emitted operation-trait obligations; their semantic laws are
stated in \path{runtime/cq-storage/src/lib.rs} and exercised by storage tests.

\paragraph{Pipeline syntax and ownership.}
Macro entries transport complete next-language programs with an explicit queue
of pass paths (ST-Next); only a terminal Rust expression ends the queue.
An ordinary enclosing Rust context supplies captures and lifetimes
(ST-Context). Printed rows borrow host/built fields; owned lookup keys and
retained dedup rows satisfy the chosen representation's Rust bounds. Computed
values remain subject to move and borrow rules. No general binding-cloning
fallback is inserted. Rust typing alone does not establish representation laws.

\paragraph{Three independent checks.}
Acceptance requires
\[
 \mathsf{RuleDerivation}(s,t)\ \land\
 \mathsf{ExpectedExpansion}(s,t)\ \land\
 \mathsf{SemanticAgreement}(s,t).
\]
The first checks the implemented structural premises and conclusions, with the
scope stated per pass in Section~\ref{sec:pass-contracts}; realization has no
independent Rust semantic checker. The second compares
each actual macro output with its authored boundary fixture, ignoring only
whitespace and source spans. The third checks representation laws and answers
with independent oracles. Equal answers cannot compensate for hardcoded dispatch,
reselection in a later pass or an omitted boundary. These test layers are independent: local/marker checking cannot substitute
for authored expansion or generated-query execution.

\paragraph{Observation and status.}
RA prime denotes bottom plus finite sets. Physical enumeration may contain multiple witnesses; its
consumer must implement the requested observation. Pure completed answers do
not establish equal partial-consumption, callback or destructor traces. Host
quotation requires binding, typing and lifetime preservation and the assumptions
of Section~\ref{sec:scope}. The core printer is pull-based; an external feature printer supports push; equality for
arbitrary callback and destructor traces is not established.
Section~\ref{sec:evaluation} lists the evidence for the implemented chain.
Documentation checks alone do not establish the runtime trait laws.
