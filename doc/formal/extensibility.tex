\section{Replacing compiler components}
\label{sec:extensibility}
Replacements satisfy the source judgment, domain, target and preservation
contracts of Theorem~\ref{thm:composition}. Typed endpoints and module-bound
continuations select logical and physical paths. Materialized, lazy and block
implementations are sibling modules; direct RA quotation bypasses planning.

\paragraph{Representations and algorithms.}
Ascent BYODS formalizes custom representations through DLDS and
concretization into facts~\cite{paper-byods}. Here a represented relation
$\gamma(s)$ must also satisfy the operations required by its chosen pass.
For key sort $K\subseteq U$ and key tuple $u$, exact lookup requires
\[
 \set(\operatorname{lookup}_K(s,u))
 =\{t\restrict(U\setminus K):t\in\gamma(s),\ t\restrict K=u\}.
\]
Membership agrees with nonemptiness; scans enumerate $\gamma(s)$.
Induction over the finite plan then preserves its completed pure answer
when providers satisfy these laws and the host assumptions. Sorted access
additionally needs order and seek laws. Rust trait signatures alone do not
establish these premises, and changing input meaning, such as adding an
equivalence closure, changes the source contract.

\paragraph{Push and multiway execution.}
A physical pass could replace local pull quotations with loops inserting
into the same materialized result sets. A public lazy Iterator instead
requires a replacement that preserves its demand and stopping contract
(Section~\ref{sec:scope})~\cite{paper-pushpull}.
A WCOJ pass must retain a complete positive join region before committing
to binary intermediates, then supply variable-prefix restriction and
intersection operations. Current index requirements describe equality keys,
not trie order or seek; using Leapfrog Triejoin would require those
additional laws and its own complexity argument~\cite{paper-lftj}.
Neither replacing a hash table alone nor treating a host function as an
enumerable relation establishes that algorithm.

\paragraph{Staging and quotation.}
Compilation specializes query structure; rows and host values remain residual.
Direct RA/Index/Access/Pipeline entries and local quotations retain binding,
typing and context contracts without reconstructing CQ
(Section~\ref{sec:constraint-planning}). The YA supplement maps choices to native
expressions, owning Rust contexts or compiler segments, with rules and algorithms
for one optional arena backend. Runtime representation choice remains ordinary
Rust; the block backend uses module-bound macro continuations.
