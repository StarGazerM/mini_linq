\section{VO: valuation plans}
\label{sec:vo}\label{sec:nf-vo}

\paragraph{Grammar.} VO extends a complete CQ$_{\rm NF}$ program with a schedule.
\begin{lstlisting}
VO   ::= CQProgram valuation [branches { JoinBranch* }] { Step* }
JoinBranch ::= branch [clause, ...] (interface, ...);
Step ::= R@path(x, _, ...); | !R(Arg, ...); | x = y; | Constraint;
       | if Expr; | let Pat [: Type] = Expr;
       | for Pat in Expr;
       | reduce R@path with S@path(...);
       | block @path(columns) { Step* } (| { Step* })+;
       | block @path(columns) { Step* } (else { Step* })+;
\end{lstlisting}
Number all NF body clauses $0,\ldots,m-1$; a path \code{R@c.j.k} names the fixed
occurrence of clause $c$, extended by branch/clause pairs per nesting level.
A subatom lists the occurrence's currently bound columns and \code{_} elsewhere.
Equalities and constraints are internal relational syntax.

\paragraph{Contract.} $\mathsf{Schedule}(t,A)$ checks:
(1)~each subatom names its relation, clause, arity and original columns; dropped
columns are unbound; every atom's full correlated row is eventually checked;
(2)~each identity, constraint and negation appears exactly once, after its
variables bind, and binds nothing; negation preserves its source atom;
(3)~Rust lets, generators and guards form the written chain (a tree under blocks, union
siblings unordered, fallback siblings ordered); each is preceded by its
free-variable binders and every source Before fact;
(4)~a reduction names a different atom or Rust-free derived block and lists
exactly the shared equality classes at its support's column positions; it
precedes the target's first subatom, except that a target already read to
supply a finite block domain restricts the retained prefix instead;
no Rust guard, scalar bind, generator or negation is a reduction target or support;
the reduction graph need not be acyclic;
(5)~blocks recursively check kind, paths, interface coverage and arm schedules;
(6)~independent join branches are disjoint connected groups of at least two
full atom occurrences in a flat, Rust-free scope. Each records exactly its
external interface and head columns; local predicates execute inside the
branch. Reductions of a member precede the first grouped read and may use
only other members, so a branch cannot depend on its future fact-side probe.
\begin{mathpar}
\Rule{D-Constraint}{\vars(C)\subseteq B}
 {\mathsf{requires}(C)=\vars(C),\quad\mathsf{provides}(C)=\emptyset}

\Rule{WF-JoinBranch}{B=\emptyset\ \lor\ \mathsf{FlatRelational}(q)\quad
 \mathsf{DisjointConnectedFullGroups}(B)\\
 \forall b\in B.\ I_b=\mathsf{Interface}(q,b)\quad
 \mathsf{EarlierBranchLocalReductions}(b)}
 {\mathsf{JoinBranches}(q,B)\Downarrow\ok}

\Rule{WF-VO}{\mathsf{WF}_{NF}(t.cq)\quad\mathsf{Schedule}(t,A)\quad
 \mathsf{JoinBranches}(t.cq,t.branches)\Downarrow\ok}
 {\mathsf{WF}_{VO}(t)\Downarrow A}
\end{mathpar}

\paragraph{Meaning.} Compose the steps in schedule order under
Section~\ref{sec:denotation}: a subatom extends valuations with matching
projected rows, a reduction is a relational semijoin on its target, negation
keeps a valuation exactly when no input row matches (CQ-Neg, E-Neg), and Rust
steps are as in CQ. By invariants (1)--(4) a schedule refines its CQ under the premises of
Section~\ref{sec:premises}, including the totality of every constraint placed
ahead of its written position (Motion lemma, Section~\ref{sec:premises}): relational
steps only moved earlier, Rust order and Before are kept, and every atom's full
row is checked.

\paragraph{Recorded decisions.} Clause order, split granularity (Coarse: one full
subatom per atom; Fine: at most one new variable per subatom), semijoin
reductions, independent exact-join branches, and block placement (hoisted
derived relation or per-row arms). An independent branch is materialized once
as the exact join of its member occurrences, projected to the recorded heading.
It assumes neither uniqueness nor foreign-key coverage.

\paragraph{Rewrite check.} Unchanged CQ; the non-reduction step erasures are equal
recursively; existing reductions are kept and added reductions satisfy the
target contract. Non-reduction steps and independent branch metadata are not
changed by a rewrite.
