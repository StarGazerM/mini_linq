\section{Quotation and composition obligations}
\label{sec:staging}
Let $C[\square^L_\Gamma]$ be a Rust context containing a quotation in language
$L$, with the runtime bindings supplied by $\Gamma$. A typed pass $f:L\to M$
has the local expansion rule
\begin{mathpar}
\Rule{ST-Entry}{\operatorname{parse}_L(T)=s\quad f(s)=t}
 {\mathsf{entry}_f\{T\}\longrightarrow\operatorname{quote}_M(t)}

\Rule{ST-Hole}{\Gamma\vdash s:L\quad f(s)=t\quad\Gamma\vdash t:M}
 {C[\square^L_\Gamma(s)]\longrightarrow C[\square^M_\Gamma(t)]}
\end{mathpar}
These rules describe composition, not permission to insert a redundant language.
The post-IX boundary has two policy steps and one printer. \code{lower_physical!}
consumes IX and the caller's query-independent policy and produces Physical;
\code{select_structures!} consumes Physical and the same policy and produces
Structures; \code{structures_to_rust!} prints one pull program and rejects
unmet premises. No pass repairs an invalid choice by selecting another one.

\paragraph{Wire slots and immediate expansions.}
The caller-resolved slots are \code{choose_index_policy!} (RA $\to$ IX),
\code{physical_policy!} (IX $\to$ Physical, the caller macro appends its
\texttt{policy \{\ldots\}} and invokes \code{lower_physical!}),
\code{select_structures!}, \code{structures_to_rust!} and
\code{distinct_state!} (the canonical return's distinct provider). Import
aliases select their implementations, without adding wrapper macros; the
composition example in \path{examples/composition/} binds every slot.

ST-Entry describes the immediate replacement produced by one entry expansion.
Each entry emits the next slot's invocation around its complete typed payload,
so a completed compilation takes several steps, $\longrightarrow^{*}$, and the
compiler can stop at any boundary for inspection.

\paragraph{An edge contract.}
Each compiler edge declares an admitted source domain, target well-formedness,
a runtime representation relation, and an observation to preserve. A residual
quotation additionally declares its required bindings and ownership lifetimes.
The preceding edge must establish these requirements. The observation may be
the completed answer set; a claim about lazy execution requires a stronger,
explicit polling observation. No proof of one automatically proves the other.

\begin{theorem}[Conditional composition]
\label{thm:composition}
Suppose $f:L\to M$ and $g:M\to N$ terminate on their declared domains,
$f$ produces only inputs admitted by $g$, and $f$ establishes the representation
and runtime preconditions required by $g$. If both preserve a common observation
under compatible closing contexts, then $g\circ f$ preserves that observation.
\end{theorem}
\begin{proof}
The first pass establishes the intermediate representation relation; the second
uses it to establish the final relation. Compose these relations and their
observation equalities. Domain inclusion establishes that the second pass is
defined. Closing-context adequacy permits the same argument for quotations.
\end{proof}

Semantic preservation and expansion conformance are independent obligations.
A generated program that returns the expected answer still fails the present
design if its macro boundaries, index identities, use references, or selected
physical operators and structures differ from the authored expansion contract.
