\section{Quotation and composition obligations}
\label{sec:staging}
Immediate macro expansions distinguish dispatch, intermediate continuation and
terminal realization. Let $T$ be tokens, $s,t$ complete typed payloads, and
$\mathsf{quote}$ their token serialization.
\begin{mathpar}

\Rule{ST-Entry}{\operatorname{parse}_{CQ}(T)=s\quad\mathsf{WF}_{CQ}(s)}
 {\code{mini_linq!}\{T\}\longrightarrow\code{mini_linq::cq_to_ra!}\{\mathsf{quote}(s)\}}

\Rule{ST-Next}{\operatorname{parse}_L(T)=s\quad f(s)=t\quad next=\mathsf{Some}(k)}
 {\mathsf{stage}(T,next,f)\longrightarrow k!\{\mathsf{quote}(t)\}}

\Rule{ST-Terminal}{\operatorname{parse}_{Structures+Policy}(T)=(s,\chi)\\
 e=\mathsf{realize}(s,\mathsf{Endpoints}(\code{mini_linq::distinct_state},\chi.intersect))}
 {\code{structures_to_rust!}\{T\}\longrightarrow\mathsf{quote}_{Rust}(e)}
\end{mathpar}
ST-Entry validates CQ and dispatches it unchanged. ST-Next is the shared
\code{cq-stage} continuation path; parse or transform failures become
\code{compile_error!}. ST-Terminal uses \code{next=None} and emits a Rust
expression. Its intersect flag is true precisely for \code{intersect=smallest}.

\paragraph{Wire slots and policy transport.}
The caller binds these slots:
\begin{center}\small
\begin{tabular}{ll}
\toprule
Slot & Input or request\\
\midrule
\code{cq_to_ra!} & CQ\\
\code{choose_index_policy!} & RA\\
\code{physical_policy!} & IX\\
\code{select_structures!} & Physical with policy\\
\code{structures_to_rust!} & Structures with policy\\
\code{distinct_state!} & Runtime distinct-state request\\
\bottomrule
\end{tabular}
\end{center}
The logical planner implementations are \path{cq_to_ra},
\path{cq_to_ra_generic} and \path{cq_to_ra_hypergraph}.
The supplied RA-to-IX implementation is \path{index_demands}. Each logical route emits
\path{choose_index_policy!} with standalone RA; \path{index_demands!} emits
\path{physical_policy!} with IX.

A caller policy wrapper appends \code{policy \{...\}} to IX and invokes
\code{lower_physical!}. The two entries forward the same policy:
\begin{lstlisting}
select_structures!  { Physical   policy { ... } }
structures_to_rust! { Structures policy { ... } }
\end{lstlisting}
Terminal realization consumes that payload and the caller's provider
path. Canon pipe or alias scans use the provider; canonical materialized storage
is read directly. The composition example in \path{examples/composition/}
starts at RA with \code{index_demands!}, defines the policy wrapper, and binds
the post-RA slots it uses. It does not bind the logical slots.

\paragraph{Abstract contexts and edge obligations.}
Let $C[\square^L_\Gamma]$ be a Rust context containing a quotation in language
$L$, with runtime bindings supplied by $\Gamma$. The implementation uses ordinary Rust macro contexts and replaces one
quotation with its checked continuation; no residual-hole IR is needed:
\[
\Rule{ST-Hole}{\Gamma\vdash s:L\quad f(s)=t\quad\Gamma\vdash t:M}
 {C[\square^L_\Gamma(s)]\longrightarrow C[\square^M_\Gamma(t)]}.
\]
ST-Hole is implemented by the stage continuation inside the caller's Rust
context. Leaf bindings and the four interfaces are checked as specified in
Section~\ref{sec:pass-contracts}. Each edge declares an admitted source domain, target
well-formedness, a representation relation and an observation to preserve.
Closing contexts must supply bindings and ownership lifetimes. A completed
answer-set observation does not establish a polling or effect-trace observation.

\begin{theorem}[Conditional composition]
\label{thm:composition}
Suppose $f:L\to M$ and $g:M\to N$ terminate on their declared domains,
$f$ produces only inputs admitted by $g$, and $f$ establishes the representation
and runtime preconditions required by $g$. If both preserve a common observation
under compatible closing contexts, then $g\circ f$ preserves that observation.
\end{theorem}
\begin{proof}
Compose the intermediate and final representation relations and their
observation equalities. Domain inclusion establishes that $g$ is defined.
Closing-context adequacy permits the same argument for quotations.
\end{proof}
Semantic preservation and authored expansion agreement remain independent
obligations. The structural checks in Section~\ref{sec:pass-contracts} do not
prove host adequacy or reproduce every construction choice.
