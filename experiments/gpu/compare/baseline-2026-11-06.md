## Method

Five interleaved AB/BA fresh-process pairs per workload, reference first in even pairs. CPU measurements acquire `flock /tmp/mini_linq-timing-gate.lock flock -x /tmp/mini_linq-timing.lock` per command. Builds use one shared timing-lock acquisition per Cargo command, `nice -n 10`, six jobs, incremental off and dev/test line-tables-only debug info. TPC-H uses the existing `performance_cpu_collect.py` generated worker and workload harness; the disposable driver limits builds to the uninstrumented worker. No counter/profile timing is mixed in. SF1 exports and transient witnesses are in `/dev/shm` and removed after collection.

TPC-H reports each worker's median of three materializing executions, with full warmup. Bench-check validates the first measured sample fully and later samples with exact logical counts plus 1000 seeded actual-row membership checks (all rows when fewer). DOOP uses an Ascent full witness for the 26-output query and the previous revision's serial full witness for field_flow; every timed result is checked, first full then sampled. Parallel runs use 24 Rayon threads. Per-process minor/major faults, peak RSS, before/after loadavg, actual command, exit status and Gate seconds are retained for every sample. The item CI exhaustively resamples paired indices (3125 draws); suite geomeans independently resample each item (20000 draws, seed 20261106). Ratios below one favor current.

## Finding: native bench-check full-witness memory defect

The initial field_flow attempt held the complete 43-relation reference index while producing another full JSON witness. The checker exited and its controller received `BrokenPipeError`; the query worker itself exited 0. That worker recorded **27,753,364 KiB max RSS (28.42 GB decimal), 7,476 major faults and 16,191,344 minor faults**, with **120.475067 s** spent producing its witness. This is a checker/transport memory defect, not evidence of a query regression. There are **103,735,854 logical rows in 43 relations**: CastTo **80,243,765**, HeapHelperNoThis **7,730,817**, HeapHelper **6,506,590**, NonStringHeapAllocSuperType **3,272,107**, VarPointsTo **2,741,586**, and InstanceFieldPointsTo **1,435,800** dominate. The precise checker exit signal was not captured; OOM is not independently established.

With Main approval, replacement DOOP samples run with **no checker process resident**. First field_flow samples export full TSV relations; later samples emit small native sampled witnesses. After collection, bench-check validates one field_flow relation at a time, preserving first-full state per binary/configuration before subsequent sampled checks. The 26-output suite likewise validates after collection. Exports/witnesses are deleted after their validation. All initial DOOP/field_flow samples and the overlapping TPC-H attempt are excluded from headline statistics and retained as aborted evidence in JSON. This transport change is measurement-only; the native checker defect is not repaired here. Validation commands use exclusive CPU timing locks and have separate Gate times in JSON.
